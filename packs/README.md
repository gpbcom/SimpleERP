# Packs

This folder holds the country and sector packs, as data. It holds no code.

- [`countries/`](countries/README.md): the signed country packs.
- [`sectors/`](sectors/README.md): the sector packs.

See [D438](../docs/specs/06-decisions/technical/d438-repository-layout.md) for the repository layout, and the
[repository layout](../docs/technical/architecture/repository-layout.md) for its tree.
