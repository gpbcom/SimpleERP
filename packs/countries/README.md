# Country packs

This folder holds the signed country packs, as data (T11). It holds no code.

See the [country packs](../../docs/specs/10-country-packs/README.md) specification,
[D438](../../docs/specs/06-decisions/technical/d438-repository-layout.md) for the repository layout, and the
[repository layout](../../docs/technical/architecture/repository-layout.md) for its tree.
