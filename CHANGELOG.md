# Changelog

Every notable change of simple-erp. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Each ticket adds one fragment in [changelog.d/](changelog.d/README.md); a release gathers them here
(`release-notes build <x.y.z>`). Never edit a released section.
