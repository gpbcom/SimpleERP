# Plugin SDK

The plugin SDK, built on `backend/models/`. It is a library with no command line: a plugin is scaffolded, tested,
packaged and signed through the local sandbox's API, the SDK's pytest fixtures and the scripts of the plugin template
([D425](../docs/specs/06-decisions/technical/d425-plugin-sdk-and-cli.md)).

See [D438 Repository layout](../docs/specs/06-decisions/technical/d438-repository-layout.md) and the
[Repository layout](../docs/technical/architecture/repository-layout.md) page.
