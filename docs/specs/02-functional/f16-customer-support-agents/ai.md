# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Classify requests, follow procedures, act through allowed connector actions, answer, judge resolutions, propose
procedure changes from corrections.

## Permissions

Each intent's procedure, allowed actions and limits (BR-F16-03).

## Models

A "Support agents" AI feature setting in F1 (D82), local by default; a separate judge model.

None.
