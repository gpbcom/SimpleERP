# 🔗 Integrations

**Status:** ✅ specified

## API

Customers, quotes, orders, invoices and payments through the API (T5).

## Webhooks

Quote accepted, invoice issued, payment received.

## MCP tools

Search customers, read and draft quotes, through T6 with the caller's rights.

## A2A skills

None in v1.

## External services

Payment providers (Stripe, Mollie, PayPal, GoCardless) and banks (F8); e-signature (Yousign, DocuSign); the e-invoicing
platform (Q13); all through T12, keys in the vault (D240).
