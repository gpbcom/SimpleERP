# 📈 Reports

**Status:** ✅ specified

## Dashboards

See [D91](../../06-decisions/f01-administration/d91-administration-reports.md), one screen per dashboard, and
[S-F1-12](screens/09-administration-reports/s-f01-12-users-overview-dashboard.md):

- **Users overview:** active, invited and deactivated users per site and role, last sign-in.
- **Access review:** who holds which rights on what, roles and record rules.
- **Connections and AI usage:** calls per connection, AI requests per feature and provider, fallbacks, requests sent
  outside.
- **Security events:** failed sign-ins, two-factor resets, provider sessions, administrators' password sign-ins under
  single sign-on.

Screens:

- [S-F1-12 Users overview dashboard](screens/09-administration-reports/s-f01-12-users-overview-dashboard.md)
- [S-F1-24 Access rights dashboard](screens/09-administration-reports/s-f01-24-access-rights-dashboard.md)
- [S-F1-25 Connections and AI usage dashboard](screens/09-administration-reports/s-f01-25-connections-and-ai-usage-dashboard.md)
- [S-F1-26 Security events dashboard](screens/09-administration-reports/s-f01-26-security-events-dashboard.md)

## KPIs

Active users; invitations pending; users without two-factor; external AI requests this month; provider
sessions this month.

## Exports

The access review and the GDPR register ([D93](../../06-decisions/f01-administration/d93-gdpr-register-draft.md)); every
report as PDF or spreadsheet.
