# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Explain why an order is late, propose a reschedule after a stop, read the next operation's instructions aloud at the
machine, summarise non-conformities and suggest causes, forecast maintenance from stops, answer a customer's substance
request from the compliance file.

## Permissions

The user's roles; approving an engineering change stays with the approvers (BR-F12-02).

## Models

"Production assistant" and "Maintenance forecast" AI feature settings in F1 (D82), local by default.

## Open questions

None.
