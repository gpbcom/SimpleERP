# 📏 BR-F12-23 A new instruction version is acknowledged before work

**Status:** ✅ specified

## Statement

When an operation's instruction has a new version, its operators acknowledge it on the tablet before starting; every
acknowledgement is kept.

## Why

Proof that people work from the current instruction.

## Examples

| Case | Result |
|---|---|
| v4 not acknowledged | Start refused |

## Applies to

- [UC-F12-28 Publish versioned work instructions](../use-cases/10-people-and-tools/uc-f12-28-publish-versioned-work-instructions.md)

## Exceptions

None.

## Configurable

No.

None.
