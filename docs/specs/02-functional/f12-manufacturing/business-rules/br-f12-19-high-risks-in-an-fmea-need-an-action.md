# 📏 BR-F12-19 High risks in an FMEA need an action

**Status:** ✅ specified

## Statement

A failure mode whose risk priority passes the bar requires an action with owner and date, and is rated again once done.

## Why

An analysis without action does not prevent failures.

## Examples

| Case | Result |
|---|---|
| Priority 160, bar 100 | Action required |

## Applies to

- [UC-F12-24 Run an FMEA](../use-cases/12-quality-engineering/uc-f12-24-run-an-fmea.md)

## Exceptions

None.

## Configurable

The bar (default: 100).

## Open questions

None.
