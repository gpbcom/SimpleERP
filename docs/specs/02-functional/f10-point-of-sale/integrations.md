# 🔗 Integrations

**Status:** ✅ specified

## API

Points of sale, sessions, orders, payments, receipts, closures through the API (T5), within roles; read-only
for closures and archives.

## Webhooks

Order paid, session closed, order ready, booking made.

## MCP tools

Every F10 action as an AI assistant tool within roles
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

## A2A skills

None in v1.

## External services

Payment terminals and tap-to-pay, QR bank payments, delivery platforms (T12 connectors, D298), table-booking sources,
SMS sending; printers, drawers, scanners, scales and displays on the local network or through a local device bridge .

## Open questions

None.
