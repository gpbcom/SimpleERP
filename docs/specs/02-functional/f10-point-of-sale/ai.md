# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Answer at the till (today's sales, a product's stock, a receipt), suggest combos and upsells, draft promotions within
the reference-price rule, forecast covers and preparation loads, explain a cash difference from the event log, translate
the menu for QR and kiosk.

## Permissions

The user's roles; sensitive till actions still need a manager's approval (BR-F10-05).

## Models

"Till assistant" and "Menu translation" AI feature settings in F1 (D82), local by default.

## Open questions

None.
