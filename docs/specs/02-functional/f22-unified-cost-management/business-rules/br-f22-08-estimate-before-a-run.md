# 📏 BR-F22-08 Estimate before a large run

**Status:** ✅ specified

## Statement

A run expected to cost more than the set amount shows its estimate and asks for confirmation first.

## Why

See [D398](../../../06-decisions/f22-unified-cost-management/d398-budgets-warn-then-stop.md).

## Examples

| Case | Result |
|---|---|
| Bulk enrichment, estimate 38 EUR | Confirmation asked |

## Applies to

Every F22 use case concerned.

## Exceptions

None.

## Configurable

Amount.

## Open questions

None.
