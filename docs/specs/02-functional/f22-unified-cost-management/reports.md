# 📈 Reports

**Status:** ✅ specified

## Dashboards

Costs per module, feature, provider and team; budgets used; forecast; anomalies; the hosted quota.

## KPIs

| KPI | Definition |
|---|---|
| Cost per active user | Paid usage over active users |
| Budget use | Spent over budget per level |
| Invoice gap | Supplier invoices against metered costs |
| Cost per document | Paid usage over documents produced (invoices, payslips) (UC-F22-24) |
| Local model share | Hours on local models over all AI hours (UC-F22-24) |
| Savings made | Measured savings of applied recommendations (UC-F22-23) |

## Exports

Usage records, allocations, invoice matches, as CSV and to accounting (F8).
