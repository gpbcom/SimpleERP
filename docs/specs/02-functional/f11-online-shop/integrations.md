# 🔗 Integrations

**Status:** ✅ specified

## API

Websites, pages, online products, carts, orders, withdrawals, reviews and analytics through the API (T5),
within roles; a headless shop front can use it.

## Webhooks

Order placed, paid, shipped; withdrawal received; cart abandoned; review posted.

## MCP tools

Every F11 action as an AI assistant tool within roles
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

## A2A skills

None in v1.

## External services

Payment providers, carriers and pickup networks, marketplaces and shop platforms (T12 connectors, D309), address and VAT
number checks, search engines (sitemaps), the domain's DNS and certificates.

## Open questions

None.
