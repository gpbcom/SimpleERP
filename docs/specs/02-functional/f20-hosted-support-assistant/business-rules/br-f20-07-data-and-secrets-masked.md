# 📏 BR-F20-07 Personal data and secrets masked

**Status:** ✅ specified

## Statement

Logs, traces and messages shown to the customer, the model or a maintainer have personal data and secrets masked.

## Why

See [D393](../../../06-decisions/f20-hosted-support-assistant/d393-hosted-support-assistant-coverage.md).

## Examples

| Case | Result |
|---|---|
| Log line with an API key | Key replaced by its name |

## Applies to

Every F20 use case concerned.

- [UC-F20-28 Report something broken from the screen](../use-cases/07-employees-help/uc-f20-28-report-something-broken-from-the-screen.md)

## Exceptions

None.

## Configurable

No.

## Open questions

None.
