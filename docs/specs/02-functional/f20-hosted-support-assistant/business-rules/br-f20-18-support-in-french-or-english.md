# 📏 BR-F20-18 Support in French or English

**Status:** ✅ specified

## Statement

The AI assistant and the human engineers answer in French or English, as the user writes or chooses; other languages get
an English answer that says so.

## Why

Customers' teams speak French or English (D477).

## Examples

| Case | Result |
|---|---|
| User writes in French | passes: French answer |
| User chooses English in their profile | passes: English answer |
| User writes in Italian | passes: English answer with a line saying so |
