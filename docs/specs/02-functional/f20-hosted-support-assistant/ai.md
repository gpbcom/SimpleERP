# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Talk a problem through in plain words, read the namespace, explain the cause, propose a fix, answer how-to questions.

## Permissions

Read-only on the namespace; every fix after a maintainer's yes (BR-F20-04).

## Models

Chosen by the publisher from the hosted edition's provider list
([D440](../../06-decisions/vision/d440-local-by-default-outside-by-choice.md)); personal data masked before any model
(BR-F20-07); health data never sent to a model unless the hosting and the model path are HDS-certified (BR-F20-13).

## Open questions

None.
