# 📏 BR-F19-17 Generated code is AGPL and stays usable

**Status:** 🔄 waiting for the owner

## Statement

A generated feature is a plugin under AGPL-3.0 like every plugin (D377); the customer can download its source at any
time and keeps the right to run it, with its data export, after cancelling.

## Why

Customers must not be locked in (D476); the copyright of AI-generated code is (Proposed) to read with
[CR-FR-203](../../../10-country-packs/france/digital/cr-fr-203-software-copyright-assignment.md) and
[CR-FR-204](../../../10-country-packs/france/digital/cr-fr-204-ai-generated-works.md).

## Examples

| Case | Result |
|---|---|
| Customer cancels gate booking | passes: source and data export available, may run it self-hosted |
| Customer asks for an exclusive licence | fails: refused, plugins are AGPL (D377) |
| Promoted feature | passes: licence to the publisher as BR-F19-10 says |
