# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Turn a need into a specification, generate the plugin and its tests, explain a check report, draft the store listing.

## Permissions

Ordering stays the owner's or administrator's; signing stays the maintainer's (BR-F19-05, BR-F19-14).

## Models

The factory's own model tier ladder, chosen by the publisher.

The publisher's providers of [D440](../../06-decisions/vision/d440-local-by-default-outside-by-choice.md), shown
read-only in the AI feature setting (E-F1-09).

None.
