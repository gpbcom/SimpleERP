# 🔗 Integrations

**Status:** ✅ specified

## API

Knowledge items can be added through the API (UC-F3-07); questions through MCP and A2A (below).

## Webhooks

None.

## MCP tools

The AI assistant's ask and draft capabilities are offered as MCP tools through T6, with the caller's rights;
changes need the caller's confirmation step (UC-F3-03).

## A2A skills

The same capabilities as A2A skills through T6.

## External services

Outside tools as a client: MCP servers, A2A agents and outside APIs from their OpenAPI description (UC-F1-07, D143),
under data categories and caps
([UC-F3-06](use-cases/06-use-an-outside-tool/uc-f03-06-use-an-outside-tool-through-the-assistant.md)); personal
connections by sign-in; synced knowledge folders (shared drives, website sections).

## Open questions

None.
