# 📏 BR-F3-40 Every figure opens its query

**Status:** ✅ specified

## Statement

Each figure in an answer links the query that produced it, in plain words and as code, with the records counted within
the user's rights.

## Why

Extends BR-F3-03: a figure is trusted because it can be checked.

## Examples

| Case | Result |
|---|---|
| 48,200 EUR in an answer | Opens the query and the 312 invoices |

## Applies to

- [UC-F3-16 See the query behind a figure](../use-cases/11-trust-the-answers/uc-f03-16-see-the-query-behind-a-figure.md)

## Exceptions

None.

## Configurable

No.

## Open questions

None.
