# 📏 BR-F3-39 Memory is opt-in, visible and erasable

**Status:** ✅ specified

## Statement

The AI assistant keeps a personal preference only when the user confirms it, shows every item in My assistant memory,
and erases any item or all at once on request; nobody else reads it.

## Why

A memory the user does not see becomes surveillance.

## Examples

| Case | Result |
|---|---|
| User says yes to keep | Kept |
| Assistant suggests, user ignores | Not kept |
| Administrator asks to read it | Refused |
