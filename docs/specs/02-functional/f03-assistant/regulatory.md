# ⚖️ Regulatory

**Status:** ✅ specified

## Rules that apply

- **EU AI Act:** users are told they are talking to an AI (the panel says so); human oversight, as every change is
  confirmed by a person (D140); a visible mention on AI-written content published to inform the public (F5, D164).
- **GDPR:** the AI assistant reads personal data only within the user's rights; personal data sent to outside tools only
  under an allowed category, logged (D169); conversations are their owner's personal data, kept for a limited time
  (D179), deleted with the account, and included in a data access request; location only with consent (D184).
