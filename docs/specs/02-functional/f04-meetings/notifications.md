# 🔔 Notifications

**Status:** ✅ specified

## Notifications

| Event | To | When |
|---|---|---|
| Bot refused entry | organiser | at once |
| Transcript ready for review | organiser | when ready |
| Review reminder | organiser | after 1 working day |
| Summary published (checked or not) | participants | at publication |
| New tasks from a meeting | task owners | at confirmation |
| Next agenda draft | participants | the day before |
| HR summary available, correction requested | employee, HR | at once |
| Recording waiting to upload for 7 days | the user | day 7 |
| Calendar to reconnect | the user | at once |
| A source failing | administrator | after retries |

## Channels

In-app; email and phone push per each user's settings (T10); the calendar event carries the agenda and summary links
(BR-F4-17).
