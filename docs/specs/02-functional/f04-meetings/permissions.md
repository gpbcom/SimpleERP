# 🔑 Permissions

**Status:** ✅ specified

## Persona × action matrix

| Action | Any internal participant | Organiser | Readers of the linked record | HR | Administrator |
|---|---|---|---|---|---|
| Start or stop a recording | ✅ (BR-F4-08) | ✅ | - | ✅ | - |
| Choose the source | - | ✅ (BR-F4-07) | - | - | - |
| Read the transcript | ✅ participants | ✅ | - | HR meetings | - |
| Read the summary | ✅ participants | ✅ | ✅ (BR-F4-04) | HR meetings | - |
| Review, turn actions into tasks | - | ✅ | - | HR meetings | - |
| Sources, calendars, retention | - | - | - | - | ✅ |

## Record rules

- Anyone can stop a recording, outside people included (BR-F4-01).
- HR meetings: HR and the employee only (BR-F4-18).
- Unchecked meetings stay with participants; links are suggestions until confirmed (BR-F4-12, BR-F4-15).
