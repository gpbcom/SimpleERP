# 🔔 Notifications

**Status:** ✅ specified

## Notifications

| Event | To | When |
|---|---|---|
| Connection failed or token refused | administrator | at once |
| Sync conflict | the record's owner | at once |
| Outside API change | administrator, maintainer | at once |
| Connector leaves the default list | administrators using it | at the yearly review |

## Channels

In-app, email, the suite's chat when connected.
