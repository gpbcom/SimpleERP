# ⚖️ Regulatory

**Status:** ✅ specified

## Rules that apply

- **EU AI Act, article 50:** AI-generated content published to inform the public is marked (BR-F5-04).
- **Consumer law:** promotional posts are identifiable as such; prices and offers follow the Code de la consommation.
- **GDPR:** messages and senders are personal data; statistics are aggregated.
- **Networks' terms:** each network's developer and content rules apply (D250).
