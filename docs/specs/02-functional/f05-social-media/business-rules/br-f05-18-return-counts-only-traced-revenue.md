# 📏 BR-F5-18 Return counts only traced revenue

**Status:** ✅ specified

## Statement

A campaign's return counts only leads and orders traced to it by a tracked link, a form or a code; untraced revenue is
shown apart, never spread.

## Why

Guessed attribution flatters every campaign.

## Examples

| Case | Result |
|---|---|
| Order through the campaign's link | Counted |
| Order with no source | Untraced share |
