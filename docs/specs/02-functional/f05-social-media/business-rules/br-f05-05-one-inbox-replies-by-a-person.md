# 📏 BR-F5-05 One inbox, replies by a person

**Status:** ✅ specified

## Statement

Comments, mentions and private messages (where each API allows) from every network land in one inbox; the AI suggests a
reply, which a person edits and sends; a sender matched to a known customer links to their record; a message that is a
support request can be turned into a customer request (F16).

## Why

Customers write where they are. See [D248](../../../06-decisions/f05-social-media/d248-social-inbox.md).

## Examples

| Case | Result |
|---|---|
| A comment asking a price | Suggested reply, sent by Léa |
| A private message about a late delivery | Turned into a customer request |
