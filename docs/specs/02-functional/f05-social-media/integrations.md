# 🔗 Integrations

**Status:** ✅ specified

## API

Posts and statistics readable through the API (T5).

## Webhooks

Incoming webhooks are external events for automatic posts (BR-F5-02).

## MCP tools

Draft and schedule a post, read statistics, through T6 with the caller's rights.

## A2A skills

None in v1.

## External services

LinkedIn, Facebook, Instagram, X, YouTube, TikTok, Mastodon, Bluesky, Threads, Google Business Profile, through their
official APIs (T12), with the install's own app, or in the hosted edition the publisher's relay under its own terms
(D250); feeds (RSS) as external events.

## Open questions

None.
