# 🔑 Permissions

**Status:** ✅ specified

## Persona × action matrix

| Action | Employees, field workers | Managers | HR | Owner | Accountants | Administrator |
|---|---|---|---|---|---|---|
| Ask legal questions | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Answers using one's own situation | ✅ own data | ✅ own and their team's they may see | ✅ | ✅ | ✅ as their rights | ✅ |
| See warnings | on their own actions | on their team's | ✅ | ✅ | on their records | - |
| Check documents | - | - | ✅ | ✅ | - | - |
| Warning and law-change reports | - | - | ✅ | ✅ | - | - |
| Law packs, warnings on or off | - | - | - | - | - | ✅ |

## Record rules

- Facts used are only those the asker may see (D12, D191).
- Legal conversations are private, from HR and administrators too (BR-F15-03).
- Warnings never reveal another person's private data (BR-F15-07).

None.
