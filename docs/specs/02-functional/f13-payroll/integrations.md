# 🔗 Integrations

**Status:** ✅ specified

## API

Pay runs, payslips (own only for employees), declarations' state and simulations through the API (T5), within roles.

## Webhooks

Run approved, payslips published, declaration accepted or rejected.

## MCP tools

Every F13 action as an AI assistant tool within roles
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

## A2A skills

None in v1.

## External services

The declaration filing service, the tax office's rates, banks for transfers (T12 connectors); external payroll providers
as an alternative (T12).

## Open questions

None.
