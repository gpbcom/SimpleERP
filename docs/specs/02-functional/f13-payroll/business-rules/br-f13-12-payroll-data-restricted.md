# 📏 BR-F13-12 Payroll data restricted

**Status:** ✅ specified

## Statement

Pay data is seen only by payroll, the employee concerned and the roles allowed; every access is logged.

## Why

See [D365](../../../06-decisions/f13-payroll/d365-payroll-coverage.md).

## Examples

| Case | Result |
|---|---|
| Manager opens a payslip | Refused |
