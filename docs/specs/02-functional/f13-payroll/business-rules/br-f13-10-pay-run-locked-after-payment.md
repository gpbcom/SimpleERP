# 📏 BR-F13-10 Pay run locked after payment

**Status:** ✅ specified

## Statement

A paid run is locked; changes go through a correction in a later run.

## Why

See [D365](../../../06-decisions/f13-payroll/d365-payroll-coverage.md).

## Examples

| Case | Result |
|---|---|
| Error found after payment | Correction next month |

## Applies to

Every F13 use case concerned.

## Exceptions

None.

## Configurable

No.

## Open questions

None.
