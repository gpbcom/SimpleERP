# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Find a plugin for a need, explain its permissions, set it up after install, summarise a check report for a publisher,
draft release notes.

## Permissions

Installing stays an administrator's confirmed action; signing stays with the store operator.

## Models

"Store assistant" AI feature setting in F1 (D82), local by default.
