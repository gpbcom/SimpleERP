# 📏 BR-F14-05 Licences checked, offline tolerant

**Status:** 🚫 withdrawn

## Statement

🚫 Withdrawn on 2026-11-12 by [D443](../../../06-decisions/vision/d443-paid-plugins-sell-support-updates-hosting.md):
paid plugins sell support, updates and hosting; no licence check is enforced and no seat is counted. It said: "A paid
plugin checks its licence at start and periodically; offline, it keeps working for a grace period."

## Why

See [D368](../../../06-decisions/f14-plugin-store/d368-plugin-store-coverage.md).

## Examples

| Case | Result |
|---|---|
| No network for 3 days | Still works, warned |

## Applies to

Every F14 use case concerned.

## Exceptions

None.

## Configurable

Grace period.

## Open questions

None.
