# 🔔 Notifications

**Status:** ✅ specified

## Notifications

| Event | To | When |
|---|---|---|
| Update available, new permission asked | administrator | at once |
| Licence expiring | administrator, owner | 30 days before |
| Checks failed, review result | publisher | at once |
| Plugin withdrawn | administrators using it, publisher | at once |
| Notice before restriction | publisher | before the restriction (BR-F14-11) |
| Payout sent | publisher | on payment |
| New review | publisher | at once |
| A country rule flagged by a law change (D294) | store operator, administrator | at once |

## Channels

In-app, email, the publisher portal.
