# 📈 Reports

**Status:** ✅ specified

## Dashboards

Requests by kind and status, time to ship, approval rate, rework, agent costs.
Per ticket built by the agent team ([FL-F25-08](flows/fl-f25-08-team-builds-a-ticket.md)): elapsed time, AI
cost, repair cycles and the maintainer's interventions.

## KPIs

| KPI | Definition |
|---|---|
| Approval rate | Agent tickets approved first time |
| Time to triage | Request to USER ticket |
| Time to ship | Request to release |
| Repair cycles | Candidate commits rejected per ticket before the draft pull request |
| First-pass verification | Tickets whose first candidate commit passes the tests and the review |

## Exports

Requests and their history.
