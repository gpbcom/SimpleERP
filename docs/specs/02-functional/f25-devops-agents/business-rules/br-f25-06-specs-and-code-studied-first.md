# 📏 BR-F25-06 Specs and code studied first

**Status:** ✅ specified

## Statement

A feature request is answered only after the agents read the specs and the code it touches; the SPECS feature cites the
pages and files it changes.

## Why

See [D432](../../../06-decisions/f25-devops-agents/d432-devops-agents-coverage.md).

## Examples

| Case | Result |
|---|---|
| Request touches F6 quotes | Tickets cite UC-F06 pages and the sales service |

## Applies to

Every F25 use case concerned.

- [UC-F25-23 Check an agent's spec pull request](../use-cases/02-feature-requests/uc-f25-23-check-an-agents-spec-pull-request.md)

## Exceptions

None.

## Configurable

No.

## Open questions

None.
