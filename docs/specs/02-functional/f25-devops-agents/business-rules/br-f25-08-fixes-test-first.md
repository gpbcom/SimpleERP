# 📏 BR-F25-08 Fixes start with a failing test

**Status:** ✅ specified

## Statement

A proposed fix starts with a test that reproduces the bug, seen failing, as for any ticket (TEST-7).

## Why

See [D432](../../../06-decisions/f25-devops-agents/d432-devops-agents-coverage.md).

## Examples

| Case | Result |
|---|---|
| Fix without a red test | Not proposed |
