# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Report a bug or request a feature from a conversation, explain a request's status, offer the feature factory.

(Proposed) Explain where an approved ticket stands in the agent team
([FL-F25-08](flows/fl-f25-08-team-builds-a-ticket.md)): its contract, the roles at work, the candidate commit and its
verdict, the draft pull request.

## Permissions

Agents write only branches, pull requests, issues and comments; maintainers approve (BR-F25-05, BR-F25-07).

## Models

Chosen by the publisher from the hosted edition's provider list
([D440](../../06-decisions/vision/d440-local-by-default-outside-by-choice.md)), through the AI gateway (D417); health
data excluded (BR-F25-13).

## Open questions

None.
