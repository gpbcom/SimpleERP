# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Build a scenario from a plain question, run it, explain the impact with figures and sources, propose and compare
counter-measures, warn when a real change hits the forecast.

## Permissions

Within the user's rights; applying an action stays a person's confirmed act (BR-F23-10).

## Models

"What-if assistant" AI feature setting in F1 (D82), local by default; the figures come from the simulation,
never from the model.

Until it has its own setting, the Default AI feature setting applies (E-F1-09, D82 extended on 2026-11-12).

None.
