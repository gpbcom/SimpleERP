# 📏 BR-F23-07 Ranges for uncertain inputs

**Status:** ✅ specified

## Statement

An uncertain input is given as a range; the result shows best, likely and worst cases and a probability range.

## Why

See [D403](../../../06-decisions/f23-what-if-simulation/d403-forecast-ranges-and-assistant.md).

## Examples

| Case | Result |
|---|---|
| Volume -5 % to -20 % | Cash in June: 42 k to 81 k, likely 63 k |

## Applies to

Every F23 use case concerned.

## Exceptions

None.

## Configurable

Number of draws.

## Open questions

None.
