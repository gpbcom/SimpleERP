# 🔗 Integrations

**Status:** ✅ specified

## API

- Custom fields and record types appear in the API (D100), under permissions (BR-F2-02).
- Record status and allowed next statuses (UC-F2-02); read-only rules apply (BR-F2-08).
- Field definitions readable (UC-F2-01); documents rendered with their template (UC-F2-05); workflows can be started
  (UC-F2-08).

## Webhooks

- Outgoing: the "send a webhook" action of rules and workflows (D126).
- Incoming: outside events that trigger rules and workflows (D125).

## MCP tools

Custom data, and starting workflows, within the caller's rights (D100, UC-F2-08).

## A2A skills

Starting workflows, within the caller's rights (UC-F2-08).

## External services

Connections of F1 (UC-F1-07), used by rules and workflows; the plugin store for packs (F14).

None.
