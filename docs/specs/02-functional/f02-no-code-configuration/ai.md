# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

- Suggest fields, write formulas, draft record types, layouts, rules and workflows, write template and email drafts,
  summarise changes, describe packs: always as drafts for the configurator.
- Run AI operations inside workflows, with a declared output format (BR-F2-14).

## Permissions

The AI assistant sees what the configurator may see; workflow AI steps run under the workflow account (BR-F2-12).

## Models

The AI assistant's setting, and "Workflow AI steps"
([D133](../../06-decisions/f01-administration/d133-workflow-ai-steps-setting.md)), local by default.
