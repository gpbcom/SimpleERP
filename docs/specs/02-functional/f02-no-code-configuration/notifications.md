# 🔔 Notifications

**Status:** ✅ specified

## Notifications

| Event | To | Source |
|---|---|---|
| Configuration published | the administrators, with a summary | D131 |
| A rule or workflow failed, a loop stopped, an AI step out of format | its author and the administrators | D137 |
| A workflow's approval or form | its person, then their manager on escalation | D137 |
| Weekly digest: automation health, unused configuration | configurators | D137 |
| A new record type available | the users of the roles ticked | UC-F2-04 |
| A pack imported | the configurators | UC-F2-11 |
| A rule paused because its author lost a right | its author | BR-F2-12 |

## Channels

In-app and email, each user can turn emails off per kind
([D92](../../06-decisions/f01-administration/d92-notification-channels.md)).
