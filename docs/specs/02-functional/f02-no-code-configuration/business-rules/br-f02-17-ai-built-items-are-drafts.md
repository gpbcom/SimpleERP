# 📏 BR-F2-17 What the AI builds is a draft

**Status:** ✅ specified

## Statement

Record types, workflows, apps and agents drafted from a description are drafts: a person reviews, previews and publishes
them like any change (UC-F2-09).

## Why

See [D300](../../../06-decisions/f02-no-code-configuration/d300-f2-benchmark-gaps.md).

## Examples

| Case | Result |
|---|---|
| "Track our vans" | Draft record type Vehicles, to review |

## Applies to

UC-F2-15

## Exceptions

None.

## Configurable

No.

## Open questions

None.
