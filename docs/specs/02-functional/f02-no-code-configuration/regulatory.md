# ⚖️ Regulatory

**Status:** ✅ specified

## Rules that apply

- Invoice mentions locked in templates (BR-F2-10); electronic invoice formats (BR-F2-11,
  [E-invoicing platforms](../../05-non-functional/e-invoicing-platforms.md)).
- GDPR: custom fields and record types holding personal data appear in the GDPR register (UC-F1-12).
- EU AI Act: AI steps that affect a person are logged and explainable (UC-F2-08).
