# 📏 BR-F17-11 Facts kept for a set period

**Status:** ✅ specified

## Statement

Collected facts are kept for the set period (default 3 years) then summarised; personal data in them follows storage
limitation.

## Why

See [D383](../../../06-decisions/f17-competitive-analysis/d383-competitive-sources-lawful.md).

## Examples

| Case | Result |
|---|---|
| Price of 2022 | Kept as a trend point only |

## Applies to

Every F17 use case concerned.

## Exceptions

None.

## Configurable

Period.

## Open questions

None.
