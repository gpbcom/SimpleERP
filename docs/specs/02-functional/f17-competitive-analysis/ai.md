# 🤖 AI

**Status:** ✅ specified

## What the AI assistant can do

Every action of this capability can be triggered from the AI assistant, within the user's roles; changes are confirmed,
irreversible acts prepared for the user
([BR-F3-34](../f03-assistant/business-rules/br-f03-34-every-capability-is-reachable-from-the-assistant.md)).

Profile a competitor, compare offers, write a sourced SWOT or battle card, summarise a week's signals.

## Permissions

Analyses within the roles granted; sources within the collection rules.

## Models

"Competitive analysis" AI feature setting in F1 (D82), local by default.

Until it has its own setting, the Default AI feature setting applies (E-F1-09, D82 extended on 2026-11-12).

## Open questions

None.
