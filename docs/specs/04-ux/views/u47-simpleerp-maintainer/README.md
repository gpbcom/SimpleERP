# 🛠️ SimpleERP maintainer: app shell and home

**Status:** 🔄 waiting for the owner

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a laptop, and on a phone for approvals. Default
density: compact ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

(Proposed) My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Pull requests to review; Agent tickets to approve.
- Widgets: Agent work waiting for a maintainer.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Pull requests to review                                 |
|  [ ] Agent tickets to approve                                |
|                                                              |
| Agent work waiting for a maintainer                          |
+--------------------------------------------------------------+
```
