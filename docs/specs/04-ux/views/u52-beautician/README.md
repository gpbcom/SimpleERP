# 💅 Beautician: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md). Devices: A tablet at the cabin or the desk; a phone
between clients. Default density: comfortable ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Read the day's bookings; Record the services and the products used; Sell products and take payments at the
  desk.
- Widgets: Meetings, Customers and sales, Purchasing and stock.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |

+--------------------------------------------------------------+
```
