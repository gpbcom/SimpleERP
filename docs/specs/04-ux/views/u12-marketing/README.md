# 📣 Marketing and communication: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md): left sidebar and top bar on a desktop, bottom tabs on
a phone. Default density: comfortable ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets, customisable ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Posts to approve; Posts scheduled today; Comments to answer.
- Widgets: Statistics this week; Editorial calendar.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Posts to approve                                        |
|  [ ] Posts scheduled today                                   |
|  [ ] Comments to answer                                      |
|                                                              |
| Statistics this we | Editorial calendar                      |
+--------------------------------------------------------------+
```
