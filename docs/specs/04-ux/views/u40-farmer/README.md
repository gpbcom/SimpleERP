# 🧑‍🌾 Farmer: app shell and home

**Status:** 🔄 waiting for the owner

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a phone in the field, often offline, and a laptop
at home. Default density: comfortable, large touch targets ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

(Proposed) My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Treatments to record; Animals to notify.
- Widgets: Weather and the week's work.
