**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a phone and a tablet on the move, a laptop at the

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).
