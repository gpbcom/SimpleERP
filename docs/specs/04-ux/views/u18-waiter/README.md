# 🍽️ Waiter: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a tablet or phone, full screen at the till or in
the kitchen. Default density: comfortable, large touch targets
([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Tables waiting; Bookings tonight.
- Widgets: Ready to serve.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Tables waiting                                          |
|  [ ] Bookings tonight                                        |
|                                                              |
| Ready to serve                                               |
+--------------------------------------------------------------+
```

## Navigation

Floor · Orders · Bookings · Session.

of sale (plugin), SC06 Restaurant and hospitality.
