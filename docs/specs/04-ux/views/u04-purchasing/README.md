# 🛍️ Purchasing and stock: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md): left sidebar and top bar on a desktop, bottom tabs on
a phone. Default density: compact ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets, customisable ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Late purchase orders; Receipts expected today; Supplier invoices to match.
- Widgets: Stock below minimum; Spend this month.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Late purchase orders                                    |
|  [ ] Receipts expected today                                 |
|  [ ] Supplier invoices to match                              |
|                                                              |
| Stock below minimu | Spend this month                        |
+--------------------------------------------------------------+
```
