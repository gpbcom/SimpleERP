# 🚚 Supplier: app shell and home

**Status:** ✅ specified

## App shell

The portal: no sidebar; a top bar with the company's logo, the document list and the account menu. Default density:
comfortable ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets, customisable ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Purchase orders to confirm; Deliveries due.
- Widgets: My invoices and their status.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Purchase orders to confirm                              |
|  [ ] Deliveries due                                          |
|                                                              |
| My invoices and th                                           |
+--------------------------------------------------------------+
```
