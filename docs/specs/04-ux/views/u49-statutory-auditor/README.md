# 🔎 Statutory auditor: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md). Devices: A laptop with two screens at the audit firm
or the client's office; the desktop is the main device. Default density: comfortable
([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Read ledgers, entries and documents; Draw samples and test them; Send and follow requests to the client.
- Widgets: Accounting, Legal assistant, Administration.

| Good morning                                [customise]      |
