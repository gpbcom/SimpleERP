# 👷 Employee: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md): left sidebar and top bar on a desktop, bottom tabs on
a phone. Default density: comfortable ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets, customisable ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: My requests and their status; Today's time entry; New meeting summaries.
- Widgets: Days off left; Next payslip; Ask the AI assistant.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] My requests and their status                            |
|  [ ] Today's time entry                                      |
|  [ ] New meeting summaries                                   |
|                                                              |
| Days off left | Next payslip | Ask the assistant             |
+--------------------------------------------------------------+
```
