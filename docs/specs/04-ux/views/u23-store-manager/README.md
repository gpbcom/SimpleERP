# 🏬 Store manager: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a tablet or phone on the shop floor and a laptop in
the back office. Default density: comfortable on the floor, compact in the office
([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Deliveries to receive; Transfers to send; Labels to print.
- Widgets: Today's sales against target.
