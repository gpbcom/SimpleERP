# 🗂️ Care coordinator: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a laptop at the office and a phone on call. Default
density: compact ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Visits without a carer; Incidents to read; Care plans to review.
- Widgets: Visits done today.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Visits without a carer                                  |
|  [ ] Incidents to read                                       |
|  [ ] Care plans to review                                    |
|                                                              |
| Visits done today                                            |
+--------------------------------------------------------------+
```
