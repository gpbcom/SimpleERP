# ✅ Quality manager: app shell and home

**Status:** 🔄 waiting for the owner

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a laptop, and a tablet on the shop floor for
audits. Default density: compact ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

(Proposed) My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).
