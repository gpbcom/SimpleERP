# 👷 Site manager: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md) on a phone or tablet on site, often offline, and on a
laptop at the office. Default density: comfortable on site, compact at the office
([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Sites to visit today; Reservations open; Progress bills to prepare.
- Widgets: Margin at completion per site.

```text
+--------------------------------------------------------------+
| Good morning                                [customise]      |
| My tasks                                                     |
|  [ ] Sites to visit today                                    |
|  [ ] Reservations open                                       |
|  [ ] Progress bills to prepare                               |
|                                                              |
| Margin at completion per site                                |
+--------------------------------------------------------------+
```
