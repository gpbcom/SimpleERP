# 🏋️ Coach: app shell and home

**Status:** ✅ specified

## App shell

The app shell of [D47](../../../06-decisions/ux/d47-app-shell.md). Devices: A phone, in the gym or on the field. Default
density: comfortable ([D42](../../../06-decisions/ux/d42-density-per-role.md)).

## Home screen

My tasks first, then the role's widgets ([D48](../../../06-decisions/ux/d48-home-screen.md)).

- My tasks: Read the day's classes and sessions; Take attendance; Note a member's progress.
