# 🔤 Typography

**Status:** ✅ specified

## Typefaces

- **Plus Jakarta Sans:** headings and dashboard figures.
- **Inter:** body text, tables and forms.
- **JetBrains Mono:** codes and IDs, such as `INV-2026-00042`.

All three are open-source and served by simple-ERP itself. See [D44](../../06-decisions/ux/d44-typefaces.md).

## Scale

| Style | Font | Size / line height | Weight |
|---|---|---|---|
| Display | Plus Jakarta Sans | 40 / 48 px | 800 |
| Heading 1 | Plus Jakarta Sans | 32 / 40 px | 700 |
| Heading 2 | Plus Jakarta Sans | 24 / 32 px | 700 |
| Heading 3 | Plus Jakarta Sans | 20 / 28 px | 600 |
| Body | Inter | 16 / 24 px | 400 |
| Body compact | Inter | 14 / 20 px | 400 |
| Label | Inter | 14 / 20 px | 500 |
| Caption | Inter | 12 / 16 px | 400 |
| Code | JetBrains Mono | 14 / 20 px | 400 |

## Usage

- Body text never below 14 px; 16 px on phones.
- Numbers in tables use Inter's tabular figures, so columns line up.
- Text can be enlarged to 200 % without loss (WCAG 1.4.4).
