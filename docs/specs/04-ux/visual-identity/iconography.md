# 🔣 Iconography

**Status:** ✅ specified

## Icon set

Lucide, served by simple-ERP itself. See [D45](../../06-decisions/ux/d45-lucide-icons.md).

## Sizes

16 px in dense tables, 20 px in buttons and menus, 24 px in the sidebar and on phones; stroke width 2.

## Usage

- An icon alone always has an accessible name.
- Plugins use Lucide too; a missing icon is drawn in its style.
