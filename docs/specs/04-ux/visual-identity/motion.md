# 🎞️ Motion

**Status:** ✅ specified

## Principles

Motion only explains a change (a panel opening, an item moving); nothing moves for decoration.

## Durations

150 ms for small changes, 250 ms for panels.

## Reduced motion

When the device asks for reduced motion, transitions are instant.
