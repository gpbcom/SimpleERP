# ✨ Principles

**Status:** ✅ specified

## Principles

1. **No training for an office worker:** every screen works without training for someone used to email, spreadsheets and
   online forms ([D33](../06-decisions/ux/d33-design-for-an-office-worker.md)); the field worker's phone screens work
   for a rare software user ([D50](../06-decisions/ux/d50-field-screens-for-rare-users.md)).
2. **Phone first for those on the move:** employees' self-service, managers and the owner, sales, customers and
   suppliers have a full phone experience ([D34](../06-decisions/ux/d34-phone-experience.md)).
3. **What needs me first:** each home screen starts with the user's tasks
   ([D48](../06-decisions/ux/d48-home-screen.md)).
4. **Density fits the job:** compact for daily data work, comfortable for occasional and mobile use, and each user can
   switch ([D42](../06-decisions/ux/d42-density-per-role.md)).
5. **The AI assistant is one click away, everywhere,** and knows what the user is looking at
   ([D49](../06-decisions/ux/d49-assistant-side-panel.md)).
6. **Accessible to everyone:** WCAG 2.2 AA and RGAA ([D46](../06-decisions/ux/d46-accessibility-standard.md)).
7. **Modern and bold, never noisy** ([D40](../06-decisions/ux/d40-modern-and-bold.md)).
8. **Works without network where the job needs it:** field tasks offline
   ([D38](../06-decisions/ux/d38-offline-field-tasks.md)).
9. **Same rules on every channel:** the screens, the AI assistant, the API, MCP and A2A show the same data under the
   same permissions ([D12](../06-decisions/foundations/d12-permissions-model.md)).
