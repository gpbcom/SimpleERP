# 🎯 Objectives

**Status:** ✅ specified

## Objectives

- 🌍 **Worldwide:** country packs written by the community, like the localisations of the leading open-source ERPs
  ([D378](../../06-decisions/vision/d378-ambition-and-measures.md)).
- 🧰 **One tool:** a company cancels its separate ERP, meeting, social media, support, legal, website and
  competitive-intelligence tools ([F17](../../02-functional/f17-competitive-analysis/README.md),
  [F18](../../02-functional/f18-hosted-websites-and-domains/README.md)).
- ⏱️ **Working in one day:** installed, set up, data imported, first invoice sent, without a consultant
  ([D379](../../06-decisions/vision/d379-working-in-one-day.md)), through the guided onboarding
  ([F21](../../02-functional/f21-onboarding-and-modules/README.md)).
- 🛡️ **Sovereign:** every part, the AI included, runs on the operator's servers by default; data goes outside only to a
  provider an administrator chooses for a feature
  ([D440](../../06-decisions/vision/d440-local-by-default-outside-by-choice.md); D1, D5).
- 🤝 **A community:** outside contributors, plugins and country packs.

## Measures

Tracked and reported, with no number set ([D378](../../06-decisions/vision/d378-ambition-and-measures.md)):

| Measure | What is counted |
|---|---|
| 🏭 Companies in production | Companies using SimpleERP daily, self-hosted and hosted |
| ⏱️ Switch without a consultant | Companies installed, imported and working within a day, with no integrator |
| 🧰 Tools replaced | Paid tools each customer cancels, and the money saved against its old tool stack |
| 🤝 Community reach | Outside contributors, community plugins, country packs written outside the publisher |
