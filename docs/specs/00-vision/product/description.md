# 📄 Description

**Status:** ✅ specified

## What SimpleERP is

SimpleERP is an open-source ERP for small and medium companies, whatever their field. It is:

- **Fully self-hosted:** every part runs on the operator's own servers, including the AI by default.
- **Extendable:** a company adapts it to its field without changing its core.
- **AI-native:** an assistant answers from the ERP's own data, and meetings become transcripts and summaries.
- **Set up by anyone:** a guided, step-by-step start in plain words, and each module switched on in one click
  ([F21](../../02-functional/f21-onboarding-and-modules/README.md)).

## Who runs it

It is run either by a company on its own server, or by an IT provider that hosts several client companies on one
platform. Both must work. See [D1](../../06-decisions/foundations/d01-runs-for-a-company-or-a-provider.md).

A third way since 2026-11-12: the **hosted edition**, run by the publisher, adds closed services around the open
product: a generated website and domain ([F18](../../02-functional/f18-hosted-websites-and-domains/README.md)), a
feature factory ([F19](../../02-functional/f19-feature-factory/README.md)), a support assistant
([F20](../../02-functional/f20-hosted-support-assistant/README.md)) and DevOps agents
([F25](../../02-functional/f25-devops-agents/README.md)). See
[D388](../../06-decisions/vision/d388-hosted-edition-open-core.md).
