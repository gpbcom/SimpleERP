# 👤 U11 IT provider administrator

**Status:** ✅ specified

## Who

Works for an IT provider that installs, updates and supports SimpleERP for several client companies (D1).

## Company examples

Not a client company: the provider's platform. See the [example companies](../example-companies/README.md).

## Goals

- Run many client companies from one place.
- Update them safely.

## Pains

- One install per client to maintain.

## Daily tasks

- Watch the platform's health.
- Answer client support requests.

## Monthly tasks

- Update, back up and restore client companies.
- Create a new client company.

## Devices

Desktop.

## Skill level

Office worker level or above: the screens need no training at that level.
