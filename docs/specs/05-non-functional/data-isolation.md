# 🧱 Data isolation

**Status:** ✅ specified

## Requirement

Each company has its own database. A fault cannot show one company's data to another, and each company is backed
up, restored, moved or deleted on its own, which a GDPR erasure request needs. See
[D19](../06-decisions/foundations/d19-one-database-per-company.md).
