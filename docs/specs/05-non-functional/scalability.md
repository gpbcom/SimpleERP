# 📈 Scalability

**Status:** ✅ specified

## Requirement

SimpleERP is built for small and medium companies, but sets no size limit: nothing in its design may stop a larger
company from using it. See [D20](../06-decisions/foundations/d20-no-size-limit.md). The first version must reach, for
one company on one install:

- 250 users working at once;
- a million documents over ten years;
- 95 % of screens answering within 1 second. See [D25](../06-decisions/foundations/d25-first-version-targets.md).
