# 🌐 Localisation

**Status:** ✅ specified

## Requirement

- French and English when the first version ships.
- Every text lives in translation files, so that the community or a plugin can add a language.
- Each user chooses their language, and each document (quote, invoice) is written in its customer's language. See
  [D21](../06-decisions/foundations/d21-languages.md).
