# 🔌 T4 Plugin runtime

**Status:** ✅ specified

## Summary

Where plugins, industry modules and generated features run, and how they are switched on (TC-02).

## Scope

- Sandbox by trust level.
- The public API and declared permissions.
- The module registry, signed packages, migrations, screens, limits.

- Planning and calculation workers for modules (REQ-T04-08).

## Functional capabilities served

F10 to F14, F19, F21, F25.

## Out of scope

- The store: F14.
- The SDK: the plugin SDK chapter (D425).
