# 🛰️ T6 MCP and A2A gateway

**Status:** ✅ specified

## Summary

SimpleERP as an MCP server and an A2A agent, and as a client of outside servers and agents.

## Scope

- MCP and A2A pods behind Kubernetes Services, autoscaled by KEDA.
- Tools, confirmations, trust, audit, metering, GitHub tools.

## Functional capabilities served

F3, F16, F19, F20, F23, F24, F25.

## Out of scope

- The API itself: T5.
