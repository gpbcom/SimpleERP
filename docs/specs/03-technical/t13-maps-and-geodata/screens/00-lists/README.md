# 🗂️ Views: Maps and geodata menu

**Status:** ✅ specified

The aggregated list views of Maps and geodata, one per record type, and the menu that lists them
([D495](../../../../06-decisions/ux/d495-views-listed-under-each-capabilitys-menu.md)). Record lists sit under the
capability's menu entry; admin lists under Administration
([D494](../../../../06-decisions/ux/d494-settings-and-technical-records-as-admin-lists.md)).
