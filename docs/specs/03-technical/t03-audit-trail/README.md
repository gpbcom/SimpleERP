# 🧾 T3 Audit trail

**Status:** ✅ specified

## Summary

What happened, who did it and with which tools, kept inalterable and searchable.

## Scope

- Every creation, change, validation, sending and AI action.
- Hash chains per company.
- Retention, erasure, search, export, provider sessions.

## Functional capabilities served

Every capability; F8 and F10 for legal records.

## Out of scope

- Metrics and logs for operations: observability (D416).
