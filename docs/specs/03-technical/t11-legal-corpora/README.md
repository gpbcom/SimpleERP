# 🏛️ T11 Legal corpora

**Status:** ✅ specified

## Summary

Each country's law and the rules SimpleERP enforces, versioned by date (TC-04).

## Scope

- Signed packs, one rules library, ingestion, change flags, community packs, tests per date.

## Functional capabilities served

Every capability that applies a legal value; F15.

## Out of scope

- The legal assistant's answers: F15.
