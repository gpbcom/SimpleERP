# ❓ Q16 How does a pilot company work before the first release?

**Status:** ✅ answered

## Question

D3 is kept: no release before every capability and the 16 sectors are built. D10 asks that one real company works in
SimpleERP for months, and the vision measures companies in production. How does a pilot run before the release?

## Why it matters

Without an answer, the first-version proof (D10) and the measures wait for the whole build.

## Options

- A pilot on development builds, with support.
- Early access for chosen companies.
- The measures start at the release only.

## Owner

The owner of SimpleERP.

## Answer

The owner, 2026-11-12 (round 3 of the review decisions): a dated pilot running F1 to F9 with e-invoicing through an
approved platform before 1 September 2027; D380 is kept for the release
([D451](../06-decisions/vision/d451-dated-pilot-before-the-release.md)).
