# 📜 D273 Other stock features

**Status:** ✅ decided

## Context

Which other stock features.

## Options

- Shipping carriers.
- Returns and scrap.
- Special stock.
- Quality checks.

## Choice

All four: carriers' rates, labels and tracking; return routes and scrap with reasons; consignment, kits, subcontracting,
packages, unit conversion, variants; quality checks at receipt, return and subcontracting.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

UC-F7-03, UC-F7-06, UC-F7-10.
