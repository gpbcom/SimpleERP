# 📜 D300 F2 benchmark additions

**Status:** ✅ decided

## Context

The owner asked that F2 to F14 cover every feature of the benchmark set (PLAN D30); a reading of the benchmark found
these gaps in F2: spreadsheets and dashboards, documents, e-signature, building with plain language and a sandbox copy
of the company.

## Options

- Add them all.
- Add with changes.

## Choice

Added, as confirmed by the owner on 2026-11-11: UC-F2-12 Build live spreadsheets and dashboards; UC-F2-13 Manage
documents in a workspace; UC-F2-14 Send documents for e-signature; UC-F2-15 Build with plain language; UC-F2-16 Try a
change in a sandbox. Each is reachable from the AI assistant within the user's roles (BR-F3-34); a legal value it needs
comes from the country pack (D293).

## Decided by

The owner, on 2026-11-11, in the specification interview.

## Consequences

New use cases, rules, entities, screens and the flow Benchmark additions.
