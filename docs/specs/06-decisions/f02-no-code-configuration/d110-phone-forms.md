# 📜 D110 Phone forms

**Status:** ✅ decided

## Context

How phone forms follow the desktop layout (D34).

## Options

- Automatic, with a phone override.
- Automatic only.
- Designed separately.

## Choice

Phone forms are derived from the desktop layout (one column, sections folded); a configurator can choose a shorter phone
layout per form.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Phones always work, with no extra design.
