# 📜 D113 A gallery of record type models

**Status:** ✅ decided

## Context

Whether a new record type can be built from a ready-made model.

## Options

- Yes, from a gallery.
- Blank only.

## Choice

Yes: a gallery of models taken from the sector packs (such as Vehicles, Equipment, Interventions, Members, Donations,
Contracts) to copy and adapt, or a blank start.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The sector packs feed the gallery.
