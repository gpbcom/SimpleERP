# 📜 D130 Workflows for non-technical users

**Status:** ✅ decided

## Context

Stated by the owner: the designer "must be understandable by non-technical users".

## Options

- Not discussed: the owner stated it.

## Choice

The workflow designer must be understandable by non-technical users: blocks read as plain sentences, no code, no
technical words, examples and templates to start from, and the AI assistant to explain or draft.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

D33 (an office worker) applies to the designer too.
