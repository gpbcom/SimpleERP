# 📜 D103 Custom fields on every record type

**Status:** ✅ decided

## Context

On which record types custom fields can be added.

## Options

- Every record type.
- A chosen list.

## Choice

Every record type of the core, of plugins and of F2's new record types, unless a plugin declares one closed.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Plugins (T4) declare whether their record types are open.
