# 📜 D111 What a new record type gets

**Status:** ✅ decided

## Context

What a new record type (such as "Vehicles") gets.

## Options

- List, form, statuses.
- A place in the sidebar.
- Links to core records.
- Attachments and comments.

## Choice

All four: its own list views, form and statuses like a core record type; an entry in the sidebar of the roles that may
see it; link fields to and from core records; files and a discussion thread on each record.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

A new record type is a first-class citizen.
