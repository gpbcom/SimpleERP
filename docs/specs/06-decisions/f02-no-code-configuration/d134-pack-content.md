# 📜 D134 What a configuration pack carries

**Status:** ✅ decided

## Context

What a configuration pack carries.

## Options

- Record types and fields.
- Templates.
- Automations.
- Roles.

## Choice

All four: custom fields, new record types, statuses, layouts and list views; document and email templates; rules and
workflows, inactive until the importer turns them on; roles and their matrices, never users.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Sector packs are configuration packs (D113, D116).
