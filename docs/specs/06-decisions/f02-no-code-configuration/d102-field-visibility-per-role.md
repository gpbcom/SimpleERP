# 📜 D102 Field visibility per role

**Status:** ✅ decided

## Context

Whether a custom field can be hidden from some roles.

## Options

- Yes, per role.
- No.

## Choice

Yes: each custom field can be limited to some roles (see, or see and change), on every channel.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Field-level rights on top of the role matrix (D76).
