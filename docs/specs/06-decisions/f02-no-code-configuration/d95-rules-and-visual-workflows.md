# 📜 D95 Simple rules and a visual designer

**Status:** ✅ decided

## Context

How powerful the workflows are.

## Options

- Simple rules.
- A visual flow designer.
- Both.

## Choice

Both: simple "when, if, then" rules for most people, and a visual flow designer (branches, loops, waits, parallel paths)
for advanced users.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Two editors over one workflow engine.
