# 📜 D117 Document template editors

**Status:** ✅ decided

## Context

How document templates are edited.

## Options

- Blocks in a visual editor.
- HTML and CSS code.
- Both.

## Choice

Both: a visual editor of blocks on an A4 page, with fields from a picker and a live preview, and an advanced HTML and
CSS mode.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Office workers use the blocks; technical users can go further.
