# 📜 D112 New record types start closed

**Status:** ✅ decided

## Context

Who sees a new record type's records by default.

## Options

- Nobody until roles allow.
- Every role, read.

## Choice

Nobody: it appears as a new row of the role matrix (D76), unticked for every role, until the configurator ticks roles.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

No data is visible by accident.
