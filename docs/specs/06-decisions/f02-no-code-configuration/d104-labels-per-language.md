# 📜 D104 Labels per language

**Status:** ✅ decided

## Context

Custom field labels and help texts in several languages (D21).

## Options

- One per language, with a fallback.
- One label only.

## Choice

A label and a help text per language the company uses; a missing one falls back to the company's main language.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Translations of configuration live with it (T10).
