# 📜 D97 Draft, preview, publish

**Status:** ✅ decided

## Context

How configuration changes are made safe.

## Options

- Draft, preview, publish.
- Live with undo.
- A sandbox copy.

## Choice

Changes are drafted, previewed with real data in a preview mode, then published; every published version is kept and can
be rolled back.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Users never see a half-made change.
