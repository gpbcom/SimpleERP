# 📜 D248 One social inbox

**Status:** ✅ decided

## Context

Where comments and messages are handled.

## Options

- One inbox, linked to customers.
- Comments only.
- No inbox.

## Choice

One inbox for all networks (comments, mentions, private messages where the API allows), AI reply suggestions sent by a
person; a known customer's message links to their record; a support request can become a customer request (F16).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

BR-F5-05.
