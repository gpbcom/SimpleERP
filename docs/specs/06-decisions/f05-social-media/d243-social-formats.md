# 📜 D243 Social formats

**Status:** ✅ decided

## Context

What content can be published.

## Options

- All formats.
- Text and images.
- Text only.

## Choice

Text, images, carousels, videos and short videos, stories where the network's API allows, links with previews, each
adapted per network (length, format, hashtags).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

BR-F5-03.
