# 📜 D12 Permissions model

**Status:** ✅ decided

## Context

How fine-grained permissions must be.

## Options

- Roles plus record rules.
- Fully custom, per field.
- Fixed simple roles.

## Choice

Permissions are editable roles plus record rules, and every channel (screens, assistant, API, MCP, A2A) obeys them.

## Decided by

The owner, on 2026-11-10, in the specification interview.
