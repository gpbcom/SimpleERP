# 📜 D2 How SimpleERP is extended

**Status:** ✅ decided

## Context

What "extendable" means for SimpleERP.

## Options

- No-code configuration.
- Plugins and modules.
- API and webhooks.
- Sector packs.
- MCP and A2A (added by the owner).

## Choice

Extension through no-code configuration, plugins, API and webhooks, sector packs, MCP and A2A.

## Decided by

The owner, on 2026-11-10, in the specification interview.
