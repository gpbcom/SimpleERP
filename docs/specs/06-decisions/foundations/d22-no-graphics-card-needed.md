# 📜 D22 No graphics card needed

**Status:** ✅ decided

## Context

The smallest server SimpleERP must run on.

## Options

- No graphics card needed.
- A graphics card required.
- A tiny server, with external AI.

## Choice

Runs with no graphics card, and works fully with the AI turned off (answers Q4).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

See the related pages.
