# 📜 D1 One company or an IT provider

**Status:** ✅ decided

## Context

Who installs and runs a SimpleERP instance in practice.

## Options

- An IT provider hosting it for many client companies.
- The company itself, on its own server.
- Both.

## Choice

Runs both as one company's install and as an IT provider's platform for several companies.

## Decided by

The owner, on 2026-11-10, in the specification interview.
