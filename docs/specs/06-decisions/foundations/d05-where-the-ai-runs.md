# 📜 D5 Where the AI runs

**Status:** ✅ decided

## Context

Fully self-hosted versus AI quality.

## Options

- Configurable per install.
- Local models only.
- External APIs only.

## Choice

AI runs on local models by default, and an external provider can be chosen per feature.
