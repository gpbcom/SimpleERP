# 📜 D181 Voice first on the phone

**Status:** ✅ decided

## Context

How central voice is on the phone.

## Options

- A voice-first option.
- Text first, with a microphone.
- Text only.

## Choice

A large microphone button; a hands-free mode, a setting, reads answers aloud and asks confirmations aloud; text stays
available.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Builds on D145; confirmations stay explicit (BR-F3-28).
