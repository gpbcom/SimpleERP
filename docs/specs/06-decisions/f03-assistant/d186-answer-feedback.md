# 📜 D186 Answer feedback

**Status:** ✅ decided

## Context

Whether users can rate answers.

## Options

- Thumbs and a reason.
- Thumbs only.
- No rating.

## Choice

Thumbs up or down on each answer, with an optional reason (wrong, incomplete, out of date, too slow); counted in the
dashboard; a thumbs down on an answer that used a knowledge item notifies that item's owner.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Feedback improves the knowledge base (UC-F3-07).
