# 📜 D185 Assistant usage dashboard

**Status:** ✅ decided

## Context

What administrators see about the AI assistant's use.

## Options

- A usage dashboard.
- Costs only.
- No reports.

## Choice

A dashboard: questions per day and per feature, changes confirmed and undone, outside calls and caps, the provider used
(local or external) and its cost, answer feedback; per role or team, never a person's content.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Administrators steer the AI assistant without reading anyone's conversations (BR-F3-33).
