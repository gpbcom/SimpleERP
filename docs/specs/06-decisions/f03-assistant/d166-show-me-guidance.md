# 📜 D166 Steps and Show me

**Status:** ✅ decided

## Context

How the AI assistant guides "how do I" questions.

## Options

- Steps and Show me.
- Text steps only.
- Do it for the user.

## Choice

Numbered steps with links to each screen, plus a "Show me" mode that highlights each button on the real screen, one step
at a time.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The user interface needs stable names for its buttons and fields, used by Show me.
