# 📜 D154 Suggested questions per record type

**Status:** ✅ decided

## Context

Whether the panel suggests questions or actions for the current screen.

## Options

- Per record type, configurable.
- A fixed list.
- None.

## Choice

Ready-made suggestions per record type ("Summarise this customer", "Why is this invoice overdue?"), shipped with
SimpleERP; configurators add their own (F2).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Sector packs can carry suggestions (D134).
