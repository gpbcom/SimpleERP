# 📜 D163 Where a draft goes

**Status:** ✅ decided

## Context

Where a draft goes.

## Options

- Into the right editor.
- Copy only.
- Saved as a document.

## Choice

"Use this draft" puts it in the email composer, the quote's text field or a new document, as a draft the user edits and
sends; "Copy" is always offered.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Consistent with D157: the AI assistant never sends (BR-F3-12).
