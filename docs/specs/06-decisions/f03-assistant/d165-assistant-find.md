# 📜 D165 Finding through the AI assistant

**Status:** ✅ decided

## Context

What happens when the user asks to find something.

## Options

- Open if one, list if several.
- Always a list.
- Records only.

## Choice

One match opens at once; several give a short list to pick from; records, screens and settings alike, within the user's
rights.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The AI assistant is also a way to navigate (BR-F3-14).
