# 📜 D149 How answers show their sources

**Status:** ✅ decided

## Context

How an AI assistant answer shows where it comes from.

## Options

- Links in the text and a closing list.
- A sources list only.
- Inline links only.

## Choice

Each fact links to its record or document in the text, and a "Sources" list closes the answer; each source opens in the
side panel.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Every answer can be checked in one click (BR-F3-01).
