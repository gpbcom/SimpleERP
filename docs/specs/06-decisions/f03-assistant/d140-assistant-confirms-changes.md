# 📜 D140 The AI assistant confirms changes

**Status:** ✅ decided

## Context

What happens before the AI assistant changes something for the user.

## Options

- Always show and confirm.
- Confirm above a threshold.
- Never ask.

## Choice

It always shows exactly what it will create or change, and the user confirms; reading needs no confirmation; bulk
changes show the full list.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Nothing changes without the user seeing it first.
