# 📜 D168 Missing features become requests

**Status:** ✅ decided

## Context

What happens when the user asks for something the ERP cannot do yet.

## Options

- Offer to send a request.
- Say it is not possible.
- Suggest a workaround.

## Choice

It says so plainly and offers to send a request to the company's configurators, pre-filled with what the user wanted;
requests are listed for them.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Configurators see what users miss (BR-F3-16).
