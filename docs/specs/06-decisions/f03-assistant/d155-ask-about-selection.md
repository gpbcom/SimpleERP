# 📜 D155 Ask about a selection

**Status:** ✅ decided

## Context

Whether the user can select something and ask about it.

## Options

- Rows and text.
- Rows only.
- No selection.

## Choice

The user selects rows in a list or a passage of text, then "Ask about the selection", also from the right-click menu.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Bulk questions on chosen rows ("total of these").
