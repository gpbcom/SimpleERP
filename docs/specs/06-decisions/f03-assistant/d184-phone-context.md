# 📜 D184 Phone context

**Status:** ✅ decided

## Context

What context the phone assistant uses.

## Options

- The current task and the day.
- The open screen only.
- Plus the location, always.

## Choice

The task or visit open on the phone and the user's tasks of the day, as a removable context chip; never the phone's
location unless the user allows it.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Field questions need no typing of the job (BR-F3-31).
