# 📜 D187 Where the AI assistant settings live

**Status:** ✅ decided

## Context

Where F3's settings live.

## Options

- F1's per-feature providers and an Administration › Assistant page.
- All on one page.
- Next to what each affects.

## Choice

"Assistant voice" (D145) and "Photo reading" (D183) join F1's per-feature providers, eight in all, local by default;
batch size (D159), conversation retention (D179), writing style (D162) and allowed personal services (D171) are grouped
on one Administration › Assistant page; caps (D172) stay on each connection.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

F1's AI settings list eight features.
