# 📜 D167 Where guidance comes from

**Status:** ✅ decided

## Context

Where guidance comes from.

## Options

- User documentation, company procedures and configuration.
- User documentation only.
- User documentation and company procedures.

## Choice

simple-ERP's user documentation, the company's own procedures in its knowledge base (UC-F3-07), and the company's
configuration (custom fields, statuses, rules), so that answers match this company's setup.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The user documentation is indexed for the AI assistant (T8) (BR-F3-15).
