# 📜 D358 SC14 use cases

**Status:** ✅ decided

## Context

The twenty proposed use cases of SC14, and the owner's addition.

## Options

- Confirm all.
- Change some.

## Choice

The twenty use cases confirmed, plus UC-SC14-21: follow features and products in Jira, GitHub or an equivalent through
MCP, an API or T12 connectors, linked to customers' requests, tickets, projects and release notes.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

UC-SC14-01 to UC-SC14-21.
