# 📜 D386 A site is tested before it goes live

**Status:** ✅ decided

## Context

The owner: the website creation must be interactive and tested before being deployed.

## Options

- Private preview, automatic checks, the customer's yes.
- The same plus a maintainer's review.

## Choice

A private preview built step by step with the AI assistant; before each publication, automatic checks (links, forms,
mobile and desktop rendering, WCAG 2.2 AA, speed, legal notices and cookie banner, careers and contact, DNS and
certificate); then the customer's yes; the previous version kept for a one-click rollback.

## Decided by

The owner, on 2026-11-12, in the specification interview.

## Consequences

BR-F18-03 to BR-F18-05.
