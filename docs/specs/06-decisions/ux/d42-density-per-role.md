# 📜 D42 Density per role

**Status:** ✅ decided

## Context

How dense the screens are.

## Options

- Comfortable with a compact option.
- Comfortable only.
- Compact only.
- Per role (the owner's answer, then the mapping shown).

## Choice

Each role has a default density: compact for purchasing, accounting, HR, administrator, external accountant, IT provider
administrator, warehouse (desktop) and office worker; comfortable for the others. Each user can override it. Phones are
always comfortable.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Density is a token set (comfortable, compact) chosen per user.
