# 📜 D41 Indigo primary colour

**Status:** ✅ decided

## Context

Which colour family for the primary colour.

## Options

- Blue or teal.
- Green.
- Indigo or purple.
- Warm orange.

## Choice

Indigo: primary #4B4FC9, accent #F2B134, success #2E7D32, error #C62828 (the palette shown with the option).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The accent is too light for text on white; it is for highlights only (computed contrast in
[Colours](../../04-ux/visual-identity/colours.md)).
