# 📜 D122 Error message standard

**Status:** ✅ decided

## Context

How error messages are written and shown, for non-technical users.

## Options

- What happened, why, what to do, with a small support reference.
- The same without reference.

## Choice

Every error message has a short title in plain words saying what happened, one sentence saying why, and the action that
fixes it as a button; the faulty field is highlighted; no code or jargon, except a small support reference at the
bottom.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

A pattern of the design system; every error image follows it.
