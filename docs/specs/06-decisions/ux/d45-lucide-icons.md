# 📜 D45 Lucide icons

**Status:** ✅ decided

## Context

Which icon set for the application.

## Options

- Lucide.
- Tabler Icons.
- Material Symbols.

## Choice

Lucide (ISC licence), served by simple-ERP itself.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Icons are line icons; plugins use the same set.
