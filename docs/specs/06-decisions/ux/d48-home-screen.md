# 📜 D48 Home screen

**Status:** ✅ decided

## Context

What a user sees first on their home screen.

## Options

- My tasks, then role widgets.
- A customisable dashboard.
- A capability launcher.

## Choice

By default, first what needs this user today (my tasks), then the widgets of their role; each user can customise it (the
owner's answer: "My tasks, then the role widget (by default) + Customizable").

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Each persona's home is drafted in its views folder.
