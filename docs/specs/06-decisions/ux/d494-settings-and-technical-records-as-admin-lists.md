# 📜 D494 Settings and technical records as admin lists

**Status:** 🔄 draft (GH-2 step S4, from VD-11 / D494)

## Context

How the settings and the technical records get their aggregated view.

## Options

- Admin lists.
- One settings explorer.
- Read-only lists.

## Choice

Admin lists: the same list page, under the Administration menu (or the hosting menu in the hosted edition), for the
administrators, the IT provider and the hosting team.

## Decided by

The owner, on 2026-11-12, in the interview on aggregated views, wording and state screens ([interview
record](../../../tickets/GH-2/resources/flowcharts-screens/INTERVIEW.md), answer 11).

## Consequences

- The rule VR-2 of the [plan](../../../tickets/GH-2/resources/flowcharts-screens/PLAN.md#view-rules) tells an admin list
  (settings, policies, preferences, templates, rules, configurations, packs, styles, mappings and technical entities)
  from a record list; 85 admin lists on 2026-11-12.
- Admin lists add [U07 Administrator](../../01-users/personas/u07-administrator.md), and [U48 Hosting
  engineer](../../01-users/personas/u48-hosting-engineer.md) for hosting records (rule VR-3).
- [C-08 Navigation](../../04-ux/design-system/components/c-08-navigation.md) lists them under Administration (change of
  step S4).
