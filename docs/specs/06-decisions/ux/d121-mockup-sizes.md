# 📜 D121 Mockup sizes

**Status:** ✅ decided

## Context

Which screen sizes the images show.

## Options

- Per persona's device.
- Desktop and phone always.
- Desktop only.

## Choice

Per persona's device: desktop (1440 x 900) for desktop personas, phone (390 x 844) for phone personas (D34), both for
those who use both; each in light and dark.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The persona pages' Devices section decides the sizes.
