# 📜 D493 Persona workspaces from the use cases

**Status:** ✅ decided

## Context

Which views a persona's workspace embeds.

## Options

- From the use cases.
- From the read permissions.
- Chosen per persona.

## Choice

A workspace embeds the views of the entities its persona works on in the use cases and flow charts.

## Decided by

The owner, on 2026-11-12, in the interview on aggregated views, wording and state screens (interview
record (the owner's interview notes of 2026-11 for the specifications, not kept in the repository), answer 10).

## Consequences

- One workspace per persona (48 today), each view opened on the persona's default saved view
  ([D484](d484-aggregated-list-view-per-record-type-and-persona-workspaces.md)).
- The views that found no persona are reviewed first (7 cards on 2026-11-12).
- The workspace sits on the persona's home screen ([D48](d48-home-screen.md),
  [D495](d495-views-listed-under-each-capabilitys-menu.md)).
