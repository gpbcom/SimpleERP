# 📜 D46 Accessibility standard

**Status:** ✅ decided

## Context

Which accessibility standard the screens meet.

## Options

- WCAG 2.2 AA and RGAA.
- WCAG 2.2 AA only.
- AAA where possible.

## Choice

WCAG 2.2 level AA everywhere, plus the French RGAA 4.1 checklist.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Every screen and component is checked against both.
