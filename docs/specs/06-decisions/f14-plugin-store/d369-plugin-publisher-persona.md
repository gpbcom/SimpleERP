# 📜 D369 Plugin publisher persona

**Status:** ✅ decided

## Context

Who publishes plugins, and who runs the store.

## Options

- A new persona U46 Plugin publisher.
- Publishers as customers of the store.

## Choice

A new persona U46 Plugin publisher. The store operator (SimpleERP's public store or an IT provider's private store) is
U11 in a store-operator role; U07 Administrator installs; U13 Owner buys; U05 Accounting.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Persona page U46.
