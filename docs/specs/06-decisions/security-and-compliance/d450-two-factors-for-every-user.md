# 📜 D450 Two factors for every user

**Status:** ✅ decided

## Context

R17: two-factor authentication for everyone (D13, D37) or only for privileged roles (the security chapter); leavers'
payslip links.

## Options

- Every user, passkeys preferred.
- Privileged roles only.

## Choice

Two factors for every user, passkeys preferred; signing in again is required before a link opens a payslip or other
personal data, a leaver's payslip link included.

## Decided by

The owner, on 2026-11-12 at 14:57, round 3 of the decisions on the independent review (R17, PROGRESS.md, step 21).

## Consequences

Revises D414 and confirms D13 and D37. The security chapter, REQ-T02-01 and Security say so.
