# 📜 D68 Invitation valid 48 hours

**Status:** ✅ decided

## Context

How long an invitation link is valid.

## Options

- 7 days.
- 48 hours.
- 30 days.

## Choice

48 hours.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

Short-lived links; an expired invitation is resent.
