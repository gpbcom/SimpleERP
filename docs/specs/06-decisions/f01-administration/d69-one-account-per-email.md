# 📜 D69 One account per email

**Status:** ✅ decided

## Context

Inviting an email that already has an account in the company.

## Options

- Refused, open that user.
- Allowed, merged.

## Choice

The invitation is refused and the existing user is shown; a deactivated user is reactivated instead (UC-F1-05).

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

An email identifies one user per company.
