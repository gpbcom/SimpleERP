# 📜 D80 External tools per role

**Status:** ✅ decided

## Context

Who may use a connected external tool through the AI assistant.

## Options

- Per role.
- Everyone.
- Administrators only.

## Choice

Per role: each connection is a row of the role matrix (D76); See gives its read tools, Change its write tools.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

No one uses a connection until a role allows it.
