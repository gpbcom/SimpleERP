# 📜 D78 Ready-made roles are copied

**Status:** ✅ decided

## Context

Whether the ready-made roles can be edited.

## Options

- No, copy then edit.
- Yes.

## Choice

No: ready-made roles stay as shipped and receive updates; the administrator copies one and edits the copy.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

An update never overwrites a company's own roles.
