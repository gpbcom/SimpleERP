# 📜 D54 Guided setup with a sector pack

**Status:** ✅ decided

## Context

What the first administrator sees on a brand-new company.

## Options

- A guided setup with a sector pack.
- An import from another tool.
- A blank company.

## Choice

A step-by-step setup: company, sites, users, sector pack (such as construction or retail), data import; it can be left
and resumed at any time.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The sector packs (D2) are chosen at setup.
