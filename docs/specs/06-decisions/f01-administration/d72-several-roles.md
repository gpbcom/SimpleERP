# 📜 D72 Several roles per user

**Status:** ✅ decided

## Context

Whether a user can hold several roles at once.

## Options

- Yes, rights add up.
- One role only.

## Choice

Yes: a user can hold several roles and gets every right of each one; the most permissive wins, record rules included.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

No combined roles are needed.
