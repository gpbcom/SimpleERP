# 📜 D229 Connecting calendars

**Status:** ✅ decided

## Context

How users' calendars are connected.

## Options

- A Workspace connection, or personal sign-ins.
- Each user signs in.
- The administrator only.

## Choice

If the company uses Google Workspace, the administrator connects it once (domain-wide) and every user's calendar syncs;
otherwise each user signs in to their own account (UC-F3-06), Google Calendar being an allowed personal service.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

UC-F4-08.
