# 📜 D233 Desktop capture, announced

**Status:** ✅ decided

## Context

the benchmarked product records from a desktop app without a bot; BR-F4-01 says every recording is announced.

## Options

- Desktop capture, announced.
- Invisible, the user's duty.
- No bot-less capture.

## Choice

A desktop app captures the computer's audio in any call without a bot, but stays announced: the user confirms everyone
was told, and a notice is posted in the call's chat when the platform allows it.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

BR-F4-19.
