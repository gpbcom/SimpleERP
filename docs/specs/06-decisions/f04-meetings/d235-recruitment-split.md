# 📜 D235 Recruitment: interviews here, the rest in F9

**Status:** ✅ decided

## Context

the benchmarked product's recruitment module: sourcing, campaigns, AI voice pre-screening, interview reports, ATS sync.

## Options

- Interviews in F4, the rest in F9.
- All in F4.
- Interviews only.

pre-screening calls become recruitment use cases of F9, interviewed there.
