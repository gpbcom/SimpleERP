# 📜 D230 Microsoft 365 calendars too

**Status:** ✅ decided

## Context

Which calendars besides Google sync the same way.

## Options

- Microsoft 365 / Outlook.
- CalDAV.
- Google only.

## Choice

Microsoft 365 / Outlook, through Microsoft Graph, with the same two-way sync; CalDAV is not in this version.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

BR-F4-17 applies to both.
