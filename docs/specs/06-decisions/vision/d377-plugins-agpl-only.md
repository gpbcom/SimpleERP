# 📜 D377 Plugins and sector packs are AGPL too

**Status:** ✅ decided

## Context

AGPL covers the core. The licence of plugins and sector packs had to be chosen.

## Options

- Any licence, through the plugin runtime and API.
- AGPL only.
- Any OSI licence, possibly paid.

## Choice

Every plugin and sector pack is AGPL-3.0.

## Decided by

The owner, on 2026-11-11, in the specification interview.

## Consequences

A paid plugin sells support and updates, not closed code. The plugin store (F14) refuses closed plugins.

Revised by D443 on 2026-11-12: a paid plugin sells support, updates and hosting; no licence check and no seat.
