# 📜 D381 A named competitor benchmark in the vision

**Status:** ✅ decided

## Context

The specs name no vendor (D27, D30). The owner asked for an exhaustive matrix comparing SimpleERP with its named
contenders, Ximi by Xelya added.

## Options

- Named, in 00-vision.
- Named in the ticket folder, unattributed in the vision.
- Both.

## Choice

The benchmark is named, in the vision, the one exception to the rule. Contenders: Odoo, ERPNext, Dolibarr, Ximi, Noota,
Nebesta, Rillet, Campfire, DualEntry, Light, Lensing, Doss and ERPClaw.

## Decided by

The owner, on 2026-11-11, in the specification interview.

## Consequences

Vendor names appear only in the benchmark pages. The capability pages stay unattributed. The benchmark is refreshed
before each release.
