# 📜 D425 Plugin SDK and CLI

**Status:** ✅ decided

## Context

Step 19n of the technical interview, from TC-02 and TC-12.

## Options

- An SDK, a CLI and a local sandbox.
- The API only.

## Choice

Confirmed by the owner on 2026-11-12: a Python SDK (TypeScript for widgets), a CLI, a local Compose sandbox, the store's
checks, generated documentation; the feature factory uses the same SDK.

## Decided by

The owner, on 2026-11-12, in the specification interview.

## Consequences

The plugin SDK chapter's target design.
