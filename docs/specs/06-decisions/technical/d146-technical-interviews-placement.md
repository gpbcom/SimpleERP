# 📜 D146 Technical design interviews before T1 to T11

**Status:** ✅ decided

## Context

The cross-cutting technical design (architecture, observability, security, deployment, data model, tests, configuration)
had no interview step; T1 to T11 cover capabilities, not these topics.

## Options

- Before T1 to T11.
- After T1 to T11.
- Inside each T capability.

## Choice

Before T1 to T11, as steps 19a to 19o, after F14 (step 19), so that the T capabilities build on them.

## Decided by

The owner, on 2026-11-10, in the specification interview.

## Consequences

The interview order becomes: functional, sectors, F13, F14, technical design topics, then T1 to T11.
