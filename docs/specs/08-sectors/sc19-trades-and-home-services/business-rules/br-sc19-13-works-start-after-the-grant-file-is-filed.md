# 📏 BR-SC19-13 Works start after the grant file is filed

**Status:** ✅ specified, ⚖️ lawyer review before launch (D574)

## Statement

The works step of an installation starts only when the grant request that must come first is filed, unless the customer
chose to go without the grant and the choice is recorded. A step is closed only with its documents.

## Why

Starting works before the request can cost the customer the grant
([D563](../../../06-decisions/sectors/d563-benchmark-gaps-sc19-trades-and-home-services.md)). (⚖️ lawyer review before launch, D574)
The France-pack rule
[CR-FR-226 Renovation grants and the RGE label](../../../10-country-packs/france/construction/cr-fr-226-renovation-grants-and-rge.md)
holds the RGE label and the site visit; that the grant request is filed before the works start is still to read (décret
n° 2020-26, Service-public F35083).

## Examples

| Case | Result |
|---|---|
| Grant request filed | works may start |
| Request not filed | works refused |
| Customer goes without a grant | choice recorded, works start |
| Document missing on a step | the step stays open |
| Customer refuses to sign the commissioning | remarks recorded, corrections planned |
