# 📏 BR-SC18-13 Sessions expire per the package terms

**Status:** ✅ specified

## Statement

Sessions of a package expire only at the end date shown in the terms the member accepted, never earlier; a session not
used by then is lost only if the terms say so, and an extension is given only with a recorded reason.

## Why

Sessions that vanish sooner than promised are a consumer complaint. The owner asked for personal training
([D562](../../../06-decisions/sectors/d562-benchmark-gaps-sc18-sports-and-fitness.md)). The consumer rules
come from the France pack, written later.

## Examples

| Case | Result |
|---|---|
| 10 sessions valid 6 months, used in 7 | the last session is lost if the terms say so |
| Extension for illness | one month, with a reason |
| Coach cancels a session | returned to the package |
| Terms not shown | the sale is blocked |
| Used up before the end date | Used up |

## Applies to

- [UC-SC18-13](../use-cases/04-personal-training/uc-sc18-13-sell-coaching-packages.md)
- [E-SC18-10 Coaching package](../data/e-sc18-10-coaching-package.md)
- [E-SC18-10 Coaching package](../data/e-sc18-10-coaching-package.md)

## Exceptions

An extension for a documented reason may go beyond the usual limit with the owner's approval.

## Configurable

The validity, the extension rules and the expiry terms of each package, by the owner.

None.
