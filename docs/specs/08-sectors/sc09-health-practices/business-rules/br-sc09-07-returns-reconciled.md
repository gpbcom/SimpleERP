# 📏 BR-SC09-07 Insurers' returns reconciled

**Status:** ✅ specified

## Statement

Payments and rejections returned by insurers are matched to care sheets; a rejection opens a task.

## Why

See [D341](../../../06-decisions/sectors/d341-health-practices-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Rejection code | Task to the secretary with the reason |

## Applies to

Every SC09 use case concerned.

## Exceptions

None.

## Configurable

No.

## Open questions

None.
