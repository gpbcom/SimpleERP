# 📏 BR-SC15-14 Returns need authorisation

**Status:** ✅ specified

## Statement

A return needs an authorisation number; goods are inspected and credited per their condition.

## Why

See [D359](../../../06-decisions/sectors/d359-wholesale-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Damaged on return | Partial credit |

## Applies to

Every SC15 use case concerned.

## Exceptions

None.

## Configurable

Return rules.

## Open questions

None.
