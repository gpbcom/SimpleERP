# 📏 BR-SC07-08 Location only while working

**Status:** ✅ specified

## Statement

The driver's phone shares its location only during trips and with consent; in France:
[CR-FR-054 Location only when needed and announced](../../../10-country-packs/france/data-protection/cr-fr-054-location-with-consent.md).

## Why

See [D335](../../../06-decisions/sectors/d335-transport-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Trip ended | Location sharing stops |

Every SC07 use case concerned.

None.

## Configurable

No.
