# 📏 BR-SC14-14 Features linked to requests

**Status:** ✅ specified

## Statement

Features and issues followed in the development tool (Jira, GitHub or equivalent, through MCP, an API or T12 connectors)
are linked to the customers' requests, tickets and release notes, both ways.

## Why

See [D358](../../../06-decisions/sectors/d358-sc14-use-cases.md).

## Examples

| Case | Result |
|---|---|
| Feature released | 7 requesting customers told |

## Applies to

Every SC14 use case concerned.

## Exceptions

None.

## Configurable

Tools connected.

## Open questions

None.
