# 📏 BR-SC14-08 Components listed in the bill of materials

**Status:** ✅ specified

## Statement

Each release keeps its software bill of materials; a new vulnerability in a component lists the releases and customers
affected.

## Why

See [D356](../../../06-decisions/sectors/d356-it-and-software-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Library CVE | 3 releases, 41 customers listed |

## Applies to

Every SC14 use case concerned.

## Exceptions

None.

## Configurable

No.

## Open questions

None.
