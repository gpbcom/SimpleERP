# 🎁 Sector pack

**Status:** ✅ specified

## Record types

Subscription, usage record, revenue schedule, licence, service level, managed asset, sprint, release note, health score,
processor agreement, component, security report, data export, dunning case, partner deal, tracked feature.

## Fields

Plan and seats on subscriptions; service level on contracts; health score on customers; tool and key on tracked
features.

## Statuses and workflows

Subscription: trial → active → suspended or ended. Security report: aware → early warning → notified → final report.

## Roles

Customer success manager (U41), developers and consultants (U16), support through F16, customers' admins and users
(U09).

## Documents

Order forms, processor agreements, invoices, release notes, security reports, export packages.

## Dashboards

MRR, ARR, churn, net retention, accounts at risk, service-level breaches, open vulnerabilities, features waited for.

## Settings

Plans, proration, dunning steps, service levels, health weights, development tools connected.

## Open questions

None.
