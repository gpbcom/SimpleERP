# 🏷️ Sectors

**Status:** ✅ specified, after F12

What each company type adds: record types, rules, documents, regulation, screens, and the sector pack that installs
them.

## Sectors and their packs

Twenty sectors ([D114](../06-decisions/sectors/d114-sixteen-sectors.md), extended by D561 to D564 on 2026-11-14), each
interviewed after F12 ([D115](../06-decisions/sectors/d115-sector-interviews-after-f12.md)) and specified in its folder
([D116](../06-decisions/sectors/d116-sectors-section.md)). A sector's pack installs its record types, fields, statuses,
workflows, roles, documents and dashboards through F2 (D113).
