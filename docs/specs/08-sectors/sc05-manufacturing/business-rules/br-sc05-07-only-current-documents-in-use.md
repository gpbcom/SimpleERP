# 📏 BR-SC05-07 Only current documents in use

**Status:** ✅ specified

## Statement

Controlled documents have versions and approvals; only the current approved version is shown on the shop floor.

## Why

See [D329](../../../06-decisions/sectors/d329-manufacturing-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Version 4 approved | Version 3 withdrawn from tablets |

## Applies to

Every SC05 use case concerned.

## Exceptions

None.

## Configurable

Approvers per document type.

## Open questions

None.
