# 📏 BR-SC20-16 Answers follow the asker's rights

**Status:** ✅ specified

## Statement

The AI assistant answers a question about the budget only with figures the asker's role may read, shows the sources of
each figure, and says so when it cannot answer. It never changes a record.

## Why

Elected officials need quick answers but must not see what their role does not allow, and a figure without a source
cannot be trusted ([D564](../../../06-decisions/sectors/d564-benchmark-gaps-sc20-public-bodies.md)).

## Examples

| Case | Result |
|---|---|
| Credit left on a chapter | answer with the figure and sources |
| A person's pay | refused, totals offered |
| Data unavailable | says it cannot be given now |
| Follow-up question | uses the same period unless changed |
| Summary for the council | a draft marked as a draft |

None.

## Configurable

The roles that may ask about each part of the budget, set by the finance officer.
