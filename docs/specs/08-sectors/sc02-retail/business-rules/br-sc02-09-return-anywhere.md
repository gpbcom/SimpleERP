# 📏 BR-SC02-09 Return anywhere

**Status:** ✅ specified

## Statement

An order from any channel can be returned in any store within the return policy; online orders keep the withdrawal
right; in France:
[CR-FR-036 Consumer withdrawal right](../../../10-country-packs/france/consumer/cr-fr-036-withdrawal-right.md).

## Why

See [D320](../../../06-decisions/sectors/d320-retail-sector-coverage.md).

## Examples

| Case | Result |
|---|---|
| Online order returned in store | Refund to the card, stock back in the store |

## Applies to

Every SC02 use case concerned.

## Exceptions

None.

## Configurable

Return period and refund means.

## Open questions

None.
