# ⚖️ CR-FR-055 Health data hosting

**Status:** ✅ specified

## Statement

Health data of patients is hosted only by a certified health data host (HDS).

## Values

- HDS deployment profile for health practices (D241).

## Legal references

- [Code de la santé publique](https://www.legifrance.gouv.fr/codes/texte_lc/LEGITEXT000006072665/) art. L1111-8.

## Effective dates

Start date to read in the official source; in force when read on 2026-11-11, the date of this specification.

in a pack update (D294).

## Exceptions
