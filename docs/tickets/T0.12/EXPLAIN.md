# T0.12: Country-pack rules library

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- A new shared library, `erp_country_rules`, answers one question: what is the value of a legal rule on the day of a fact.
- A country pack is a YAML file of rules, each with dated versions. Last year's invoice gets last year's value, and a future-dated value applies from its date.
- A value is an exact decimal or an amount with its currency. A float is refused, so sums carry no float error.
- Bad input is refused with an explicit error: an unknown country, an unknown rule, a date outside every version, overlapping versions.

## ⚙️ How it works

1. **The caller asks for a value:** `CountryRules.value(rule, country, date)` is the entry point (I-T11-01), in [`backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py:91`](../../../backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py#L91).
2. **The pack is fetched:** the service asks the repository for the country, in [`backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py:107`](../../../backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py#L107).
3. **The country is checked before any path is built:** it is stripped, upper-cased and must be two ASCII letters, otherwise `SECountryPackNotFoundError`, in [`backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py:61-67`](../../../backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py#L61-L67).
4. **The cache is read, then the file:** a pack already loaded is returned at once ([line 68-71](../../../backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py#L68-L71)). Otherwise the path `<packs_dir>/<cc>/rules.yaml` is built from the configuration ([line 72](../../../backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py#L72)), and a missing file is refused ([lines 73-75](../../../backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py#L73-L75)).
5. **The file is loaded and validated:** `CountryPack.load` is a `YamlCatalog` ([`backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py:22`](../../../backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py#L22)). It checks the country code ([line 51](../../../backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py#L51)), the version text ([line 71](../../../backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py#L71)), the rules list ([line 91](../../../backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py#L91)) and that no rule name appears twice ([line 117](../../../backend/shared/country-rules/src/erp_country_rules/models/packs/country_pack.py#L117)). A pack that loads is kept in memory ([line 81](../../../backend/shared/country-rules/src/erp_country_rules/storage/packs/country_pack_repository.py#L81)).
6. **Each version is validated:** dates must be dates or ISO strings, never a `datetime` ([`backend/shared/country-rules/src/erp_country_rules/models/rules/rule_version.py:48-67`](../../../backend/shared/country-rules/src/erp_country_rules/models/rules/rule_version.py#L48-L67)). The value is a `Money`, a money mapping or an exact `Decimal`, and a float or a boolean is refused ([line 117](../../../backend/shared/country-rules/src/erp_country_rules/models/rules/rule_version.py#L117)). A version may not end before it starts ([line 160](../../../backend/shared/country-rules/src/erp_country_rules/models/rules/rule_version.py#L160)).
7. **Versions never overlap:** `CountryRule.validate_periods` refuses versions out of order or overlapping, and an open-ended version that is not the last, in [`backend/shared/country-rules/src/erp_country_rules/models/rules/country_rule.py:86-102`](../../../backend/shared/country-rules/src/erp_country_rules/models/rules/country_rule.py#L86-L102). This is what guarantees one value per day.
8. **The rule is found by name**, else `SECountryRuleNotFoundError`, in [`backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py:46-63`](../../../backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py#L46-L63).
9. **The version in force is found:** the first version with `valid_from <= date` and `date <= valid_to` (or no `valid_to`) wins. A date in a gap or before the first version raises `SECountryRuleNotInForceError`, in [`backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py:79-85`](../../../backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py#L79-L85).
10. **The value is returned**, with a DEBUG line that never quotes it, in [`backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py:109-112`](../../../backend/shared/country-rules/src/erp_country_rules/service/rules/country_rules.py#L109-L112).

The folder is set by `CountryRulesConfig.packs_dir`, default `packs/countries` (D438), in [`backend/shared/country-rules/src/erp_country_rules/models/config/country_rules_config.py:25`](../../../backend/shared/country-rules/src/erp_country_rules/models/config/country_rules_config.py#L25).

## 📝 Assumptions accepted

- Package `erp_country_rules` and distribution `erp-country-rules`: the specifications name only the folder (D438), and the `erp_` prefix matches `erp_models`.
- Pack file `<packs_dir>/<country lower case>/rules.yaml` holds `country`, `version` and `rules`; each version holds `valid_from`, `valid_to` and `value` (main fields of E-T11-01 and E-T11-02, signature out of scope per REQ-T11-01).
- `valid_to` is inclusive and optional, versions never overlap, and a date in a gap or before the first version is refused (most conservative reading of REQ-T11-02).
- A value is an exact `Decimal` or an `erp_models` `Money`, and a float is refused (REQ-T10-03). Text and boolean values are left to later tickets.
- The country is checked as two ASCII letters before any path is built, against path traversal.
- The default `packs_dir` is `packs/countries` (D438), and no real pack data is added.
- The test pack is a synthetic country ZZ with fixed dates (D426).
- `value()` logs DEBUG on success and ERROR before each refusal, and never logs a value.
- No api layer and no factory, because the library is not a runnable.
- REQ-T11-06 criterion 2 (release blocked) is out of scope; criterion 1 is enforced by `test_every_rate_change_has_a_case_before_and_on_its_date`.
- No screen and no budget: a back-end library with no measure in the roadmap row.
- [`uv.lock`](../../../uv.lock) sits outside the ticket's area, but a new workspace member needs it. The root [`pyproject.toml`](../../../pyproject.toml) is unchanged because its glob `backend/shared/*` covers the member.
