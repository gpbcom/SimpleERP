# T0.13: Test helpers library

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- Adds the shared test library `erp_testing`, with no business rules, for the tests of every service.
- Offers a local HTTP stand-in server whose unconfigured routes answer a valid empty value of their real model (TEST-2).
- Starts a PostgreSQL test server once per session from the local binaries, and skips its tests with a reason where the binaries are missing.
- Gives synthetic company and user builders, a company-context fixture, and log capture, all exposed as pytest fixtures by one plugin class.
- Uses no mock library, and no production data: all data comes from a catalogue of invented words and reserved test domains.

## ⚙️ How it works

1. **Register the plugin:** a consumer's `conftest.py` registers one `TestingPlugin` instance, as the library's own does in [`backend/shared/testing/tests/plugin/conftest.py:8`](../../../backend/shared/testing/tests/plugin/conftest.py#L8). The class and its logger are in [`backend/shared/testing/src/erp_testing/plugin/testing_plugin.py:24-42`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L24-L42).
2. **Stand-in server fixture:** [`stand_in_server`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L48) builds the server through its factory ([`stand_in_server_factory.py:37`](../../../backend/shared/testing/src/erp_testing/factories/stand_in/stand_in_server_factory.py#L37)), initialises it and closes it in a `finally`.
3. **Routes and answers:** a route is registered in [`stand_in_server.py:83`](../../../backend/shared/testing/src/erp_testing/stand_in/stand_in_server.py#L83). A non-list route whose model cannot be built empty is refused at that point (`SEStandInServerNoEmptyValueError`, lines 93-101). `answer()` ([line 104](../../../backend/shared/testing/src/erp_testing/stand_in/stand_in_server.py#L104)) replaces the default for a registered route.
4. **A request arrives:** [`stand_in_handler.py:84`](../../../backend/shared/testing/src/erp_testing/stand_in/stand_in_handler.py#L84) records it, looks the route up, answers 404 when none matches (line 98), the configured answer when one exists (line 106), else the empty value of the route's model built by [`empty_body`](../../../backend/shared/testing/src/erp_testing/stand_in/stand_in_handler.py#L71) (line 104).
5. **PostgreSQL server fixture:** [`postgres_server`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L64) is session scoped. It calls `initialize()` ([`postgres_test_server.py:186`](../../../backend/shared/testing/src/erp_testing/postgres/postgres_test_server.py#L186)), which finds the binaries, makes a temporary folder, runs `initdb`, starts `pg_ctl` on a free port, waits for readiness and creates the database.
6. **Finding the binaries:** [`postgres_binaries.py:120`](../../../backend/shared/testing/src/erp_testing/postgres/postgres_binaries.py#L120) searches the configured folders, then `PATH`, then `pg_config`. When none holds all four tools it logs and raises `SEPostgresBinariesNotFoundError`, which the fixture turns into `pytest.skip` ([`testing_plugin.py:78-80`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L78-L80)); `close()` still runs ([line 83](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L83)).
7. **Synthetic data:** [`synthetic_catalog`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L87) loads the shipped catalogue ([`synthetic_catalog.py:45`](../../../backend/shared/testing/src/erp_testing/models/synthetic/synthetic_catalog.py#L45), data in [`synthetic.yaml`](../../../backend/shared/testing/conf/catalogs/synthetic.yaml)). `company_builder` ([line 97](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L97)) and `user_builder` ([line 110](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L110)) seed from `0`. A company is built from a seeded random generator in [`company_builder.py:60`](../../../backend/shared/testing/src/erp_testing/synthetic/company_builder.py#L60).
8. **Company context:** [`company_context`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L124) takes the company from `user_builder.company` and the user from `user_builder.build()` (line 134), so both name the same company. [`SyntheticCompanyContext.context`](../../../backend/shared/testing/src/erp_testing/context/synthetic_company_context.py#L54) builds T0.09's `RequestContext` from them (line 63 area), entered as a `with` block.
9. **Log capture:** [`log_capture`](../../../backend/shared/testing/src/erp_testing/plugin/testing_plugin.py#L140) attaches a [`LogCapture`](../../../backend/shared/testing/src/erp_testing/logs/log_capture.py#L10) handler and detaches it in a `finally`; tests read it with `messages()` and `contains()`.
10. **No mock library:** [`test_no_mock_library.py:44`](../../../backend/shared/testing/tests/test_no_mock_library.py#L44) reads the package's dependencies and [line 47](../../../backend/shared/testing/tests/test_no_mock_library.py#L47) scans `src` and `tests` for mock imports.
