# T0.15: Base UI components

**Status:** ✅ Done · **Ticket:** [TICKET.md](TICKET.md) · **Choices and trade-offs:** [IMPLEMENTATION.md](IMPLEMENTATION.md) · **Review:** [REVIEW.md](REVIEW.md)

## 🔭 What it does

- Adds the package `@simpleerp/ui`, the component library of the back office, built on the design tokens.
- Delivers the six base components: button, form field, navigation item, toast, modal and card, with the icon and spinner they share.
- Every component works in the light and the dark theme, can be used with the keyboard with a visible focus, and takes its colours, spacing, radius and elevation from the tokens only.
- Lucide icons come from the package `lucide-vue-next`, and nothing is fetched from a third party.
- Ships Vitest tests in both themes, an automated accessibility check (axe-core) on each component, and style and build tests.

## ⚙️ How it works

1. **Package and exports:** the package declares its dependencies, its exports and its scripts in [`frontend/packages/ui/package.json`](../../../frontend/packages/ui/package.json#L1). The `test` and `typecheck` scripts build the tokens package first ([`frontend/packages/ui/package.json:19-20`](../../../frontend/packages/ui/package.json#L19-L20)), because the tests read `tokens/dist`.
2. **Entry point:** [`frontend/packages/ui/src/index.ts:1-8`](../../../frontend/packages/ui/src/index.ts#L1-L8) exports the six components and the two shared ones by name.
3. **Build:** [`frontend/packages/ui/vite.config.ts:5-17`](../../../frontend/packages/ui/vite.config.ts#L5-L17) builds one ES module and one CSS file, and makes `vue`, `lucide-vue-next` and the tokens external.
4. **Shared icon and spinner:** [`frontend/packages/ui/src/components/UiIcon.vue:23`](../../../frontend/packages/ui/src/components/UiIcon.vue#L23) draws a Lucide icon in `currentColor`; [`frontend/packages/ui/src/components/UiSpinner.vue`](../../../frontend/packages/ui/src/components/UiSpinner.vue) is the loading indicator. The button and the toast use them.
5. **Themes:** a component never tests the theme. Each style reads CSS variables of the tokens, and the `data-theme` attribute of the page switches their values. Hover mixes 8 % of `color-text` into the colour, as in [`frontend/packages/ui/src/components/UiButton.vue:144`](../../../frontend/packages/ui/src/components/UiButton.vue#L144): darker in light mode, lighter in dark mode.
6. **Button:** the attributes are computed in [`frontend/packages/ui/src/components/UiButton.vue:49-55`](../../../frontend/packages/ui/src/components/UiButton.vue#L49-L55): `aria-label` for an icon-only button, `title` for a disabled reason, `aria-busy` and `aria-disabled` while loading.
7. **Form field:** the control has a 1 px edge ([`frontend/packages/ui/src/components/UiFormField.vue:134`](../../../frontend/packages/ui/src/components/UiFormField.vue#L134)), a 2 px primary edge on focus ([`frontend/packages/ui/src/components/UiFormField.vue:142-144`](../../../frontend/packages/ui/src/components/UiFormField.vue#L142-L144)) and a 2 px error edge ([`frontend/packages/ui/src/components/UiFormField.vue:156-159`](../../../frontend/packages/ui/src/components/UiFormField.vue#L156-L159)). The input carries `aria-describedby` and `aria-invalid` ([`frontend/packages/ui/src/components/UiFormField.vue:92-93`](../../../frontend/packages/ui/src/components/UiFormField.vue#L92-L93)).
8. **Navigation item:** the item of C-08 sets `aria-current="page"` on the current page ([`frontend/packages/ui/src/components/UiNavItem.vue:30`](../../../frontend/packages/ui/src/components/UiNavItem.vue#L30)). The sidebar itself is left to T0.17.
9. **Toast:** it has `role="status"` ([`frontend/packages/ui/src/components/UiToast.vue:59`](../../../frontend/packages/ui/src/components/UiToast.vue#L59)) and never takes the focus. `resume` starts a countdown of `durationMs` unless the toast has an action ([`frontend/packages/ui/src/components/UiToast.vue:35-42`](../../../frontend/packages/ui/src/components/UiToast.vue#L35-L42)); `pause` keeps the time left ([`frontend/packages/ui/src/components/UiToast.vue:45-49`](../../../frontend/packages/ui/src/components/UiToast.vue#L45-L49)). Hover and focus pause it, leaving resumes it ([`frontend/packages/ui/src/components/UiToast.vue:60-63`](../../../frontend/packages/ui/src/components/UiToast.vue#L60-L63)).
10. **Modal:** the panel is a `dialog`, or an `alertdialog` for the error variant ([`frontend/packages/ui/src/components/UiModal.vue:111`](../../../frontend/packages/ui/src/components/UiModal.vue#L111)). It records the opener and moves the focus inside on open ([`frontend/packages/ui/src/components/UiModal.vue:62-67`](../../../frontend/packages/ui/src/components/UiModal.vue#L62-L67)), gives it back on close ([`frontend/packages/ui/src/components/UiModal.vue:45-47`](../../../frontend/packages/ui/src/components/UiModal.vue#L45-L47)), and `onKeydown` closes on Escape and keeps Tab inside the panel ([`frontend/packages/ui/src/components/UiModal.vue:75-98`](../../../frontend/packages/ui/src/components/UiModal.vue#L75-L98)). On a phone the panel rises from the bottom ([`frontend/packages/ui/src/components/UiModal.vue:240`](../../../frontend/packages/ui/src/components/UiModal.vue#L240)).
11. **Card:** a selectable card renders a real radio button or checkbox ([`frontend/packages/ui/src/components/UiCard.vue:63`](../../../frontend/packages/ui/src/components/UiCard.vue#L63)), and the title is a heading of the chosen level ([`frontend/packages/ui/src/components/UiCard.vue:74`](../../../frontend/packages/ui/src/components/UiCard.vue#L74)).
12. **Test set-up:** [`frontend/packages/ui/vitest.config.ts:5-10`](../../../frontend/packages/ui/vitest.config.ts#L5-L10) runs jsdom with [`frontend/packages/ui/tests/setup.ts`](../../../frontend/packages/ui/tests/setup.ts), which loads the tokens CSS. [`frontend/packages/ui/tests/helpers/expect-no-axe-violations.ts`](../../../frontend/packages/ui/tests/helpers/expect-no-axe-violations.ts) runs axe-core with the WCAG 2.0 to 2.2 A and AA tags, contrast left out because jsdom cannot compute it.
13. **Static style tests:** [`frontend/packages/ui/tests/styles/component-styles.ts`](../../../frontend/packages/ui/tests/styles/component-styles.ts) parses each component's `<style>` with postcss. [`frontend/packages/ui/tests/styles/tokens-only.spec.ts`](../../../frontend/packages/ui/tests/styles/tokens-only.spec.ts) and [`frontend/packages/ui/tests/styles/focus-visible.spec.ts`](../../../frontend/packages/ui/tests/styles/focus-visible.spec.ts) check that only tokens are used and that the focus ring is a 2 px primary one.
14. **No third party:** [`frontend/packages/ui/tests/build/no-third-party.spec.ts`](../../../frontend/packages/ui/tests/build/no-third-party.spec.ts) checks that `src` holds no URL, that icons come from `lucide-vue-next` at an exact version, and that the build output holds no URL.

## 📝 Assumptions accepted
