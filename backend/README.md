# backend

The Python back end of SimpleERP. It is made of `models/`, the shared Pydantic models of every public contract,
`shared/`, the libraries the services share, and `services/`, one micro-service per folder.

See [D438, the repository layout](../docs/specs/06-decisions/technical/d438-repository-layout.md) and the
[repository layout](../docs/technical/architecture/repository-layout.md).
